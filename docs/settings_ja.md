# 設定画面の案内

右上の歯車 **設定** を開くと、用途ごとの5つのタブがあります。各タブは説明、項目のまとまり、操作ボタンの順に並びます。

| タブ | 設定する内容 | 保存と反映 |
| --- | --- | --- |
| 会話 | 人格、記憶、能動的な話しかけ、Web検索・画像送信の許可 | チェックはすぐ保存。人格・話しかけは各編集画面の「保存」、記憶は管理画面の操作で反映 |
| 音声 | 音声認識方式、使用マイク、録音の調整、音声を使う会話の動作 | チェックはすぐ保存。「マイクの設定」は保存後すぐ反映 |
| 表示 | フローティング通知、最前面表示、雨衣の回転、正面への復帰、モーション・表情の管理 | 表示の変更は自動保存。通知の時間は次の通知から反映。登録内容は各管理画面で保存 |
| 環境設定 | LLM接続先の追加・編集・削除・選択、APIキー・URL・モデル名、VoiSona Talkの接続情報・ボイス名 | 「LLM・VoiSona Talkの接続設定」でまとめて保存し、再起動後に反映 |
| 診断情報 | 現在のプロバイダー・モデル、音声やアバターの状態 | 確認専用 |

## AIや読み上げを接続する

**設定 → 環境設定 → LLM・VoiSona Talkの接続設定** を開きます。**使用するLLM接続先** を選び、画面入力を使う場合は **環境変数で設定** のチェックを外して接続情報を入力します。**保存（再起動後に反映）→アプリを終了→起動** の順で切り替わります。接続先を選ぶ別の画面はありません。[詳しい導入手順](environment_settings_ja.md) を参照してください。

画面上部の **現在使用中** は起動中の接続先と方式です。入力欄は次回起動に使う値です。保存だけでは接続テストや外部送信をしません。

保存前の確認には、接続先を選んでURL・モデル名・APIキーを入力し、**接続テスト** を押します。短い固定文を1回送るため、料金が発生する場合があります。結果は画面上部に日本語で表示し、テストだけでは保存しません。環境変数方式では環境変数の値を使います。音声は対象外です。[詳しい手順とエラーへの対処](environment_settings_ja.md#保存前に接続を確認する) を参照してください。

音声欄の下には **VoiSona Talkの接続テスト・試聴** と **試聴を停止** があります。保存前のURL・ユーザー名・パスワード・ボイス名で認証とボイス名を確認し、短い固定文を合成して再生します。合成中・再生中・終了と失敗理由を日本語で表示します。VoiSona Talkを同じPCで起動して使います。[試聴の操作と復旧](environment_settings_ja.md#保存前にvoisona-talkを試聴する) を参照してください。

画面入力方式では、同じ場所の **ボイス一覧から選ぶ** で、未保存のURL・ユーザー名・パスワードから導入済みボイスを取得できます。選択画面で名前を選び **選択** を押すとボイス名欄へ反映します。一覧の取得だけでは合成・再生・保存せず、取得失敗やキャンセルでは現在の名前を保持します。[詳しい一覧選択の手順](environment_settings_ja.md#ボイス名を一覧から選ぶ) を参照してください。

一覧にないOpenAI互換の接続先は、**環境変数で設定** のチェックを外して **接続先を追加** から登録します。既存の接続先を選ぶと接続情報を編集でき、**名前を変更** で呼び名を変えられます。追加・編集も同じ **保存** でまとめて反映予約し、**キャンセル** なら保存しません。認証情報の保護方式は変わりません。

不要な接続先は、一覧で対象を選んで **接続先を削除** を押します。確認画面で対象名と削除後の接続先を確認し、**削除を予約 → 保存 → 終了 → 起動** と操作します。保存時に対応する保護済みAPIキーも削除し、他の認証情報は残します。確認の初期選択はキャンセルです。復旧用のmockと最後の1件は削除できません。[詳しい削除手順](environment_settings_ja.md#接続先と保存済みapiキーを削除する) を参照してください。

## マイクを調整する

**設定 → 音声 → マイクの設定** で、認識方式・使用マイク・録音を調整します。**保存** を押すとすぐに反映します。APIキーや使用するLLMはこの画面にありません。

## キャンセルと閉じる

編集画面の **キャンセル** では入力を保存せず、元のタブに戻ります。設定本体の **閉じる** は会話画面へ戻ります。既に反映・保存したチェック・通知時間の変更や管理操作を取り消すボタンではありません。

接続設定の保存に失敗した場合は入力を保持し、通常は前の接続先と認証情報を維持します。接続先の復元にも失敗したという案内が出た場合は、再起動を止め、編集画面を閉じずに保存先の権限を確認してから、保存をやり直してください。認証・接続エラーが続く場合は送信を止め、必要なら環境変数方式へ戻して保存・再起動します。秘密値をエラー報告へ貼り付けないでください。

## 通知の表示と時間を変える

1. **設定 → 表示** を開き、**フローティング通知** の項目を探します。
2. **記憶の通知を表示**、**通常の案内を表示** を、それぞれオン・オフします。オフにすると表示中の同じ種類の通知も閉じます。
3. 各項目の **表示時間** を1～30秒で変更します。矢印では0.5秒ずつ変更できます。数字を直接入力した場合はEnterで確定します。
4. **閉じる** で会話へ戻ります。変更は自動保存され、再起動後も保持されます。時間は次の通知から使います。

初期値は両方オン、記憶の通知6秒、通常の案内3.5秒です。同じ値に戻せば元の表示になります。非表示でも記憶の保存・候補の作成は続き、**設定 → 会話 → 記憶を管理** で確認できます。エラーや処理中の表示、停止・取消ボタンはこの設定の対象外です。

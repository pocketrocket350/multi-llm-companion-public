# はじめての起動

Windows 11とPython 3.12を使います。初回はインターネット接続が必要です。最初は外部AIへ接続しない **Mock** で起動するため、APIキーや音声・MMD素材は不要です。

## 1. 準備する

1. [Python公式のWindows配布一覧](https://www.python.org/downloads/windows/)からPython 3.12を導入します。インストーラーで **Add python.exe to PATH** をオンにします。
2. アプリのソースZIPを右クリックし、**すべて展開** を選びます。ドキュメントなど、書き込みできる新しいフォルダーを使います。既存のアプリへ重ねて展開しません。
3. 展開先を開き、`setup_windows.bat` と `run.bat` が見えることを確認します。ZIP内から直接実行しないでください。

配布ファイルとハッシュの確認方法は [こちら](release_ja.md) です。

## 2. セットアップする

1. `setup_windows.bat` をダブルクリックします。
2. **セットアップが正常に終わりました** と表示されるまで待ちます。
3. `run.bat` をダブルクリックします。

アプリ専用のPython環境 `.venv` と利用者設定 `local` を用意し、カタログがまだない場合は同梱VMDを配置します。既存の設定とカタログは上書きしません。初期状態では音声・3D・能動的な話しかけは無効です。

## 3. 会話して終了する

1. 入力欄に「こんにちは」と書き、Enterまたは **送信** を押します。Shift+Enterは改行です。
2. Mockの回答が表示されたら起動成功です。接続先は右上の歯車 **設定 → 診断情報** で確認できます。
3. 回答が終わったら、ウィンドウ右上の **×** で終了します。
4. `run.bat` で再起動し、左上の三本バー **履歴** から先ほどの会話を選びます。

画面が開かない・回答や履歴が出ない場合は、表示されたエラーを控えて [復旧手順](backup_and_recovery_ja.md#起動や接続で困ったとき) へ進みます。

## 次の設定

- AIと会話する：[LLM接続](providers_ja.md)
- 雨衣の音声・MMDを使う：[基準構成の設定](reference_setup_ja.md)
- 履歴、検索、画像など：[会話の操作](conversation_ja.md)

設定ファイルを編集するときはアプリを終了し、対象を別名でコピーしておきます。普段は `config` の見本ではなく `local` 内を編集します。メモ帳でUTF-8のまま保存し、字下げの半角スペースを崩さず、拡張子を `.yaml.txt` にしないでください。

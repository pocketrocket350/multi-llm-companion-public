## 初回セットアップと使い方

1. 修正版候補を新しい書き込み可能なフォルダーへ展開します。既存のアプリフォルダーへ重ねて展開しません。
2. `setup_windows.bat` を開きます。通常のセットアップに続いて、`bundled`の一覧とハッシュを照合し、VMD・規約・権利記録を`local/motions/otokam`と`local/licenses/otokam`へ、カタログを`local/vmd_catalog.yaml`へ配置します。
3. 初期状態はMock文字会話と2D表示です。PMXや音声の読込み・外部送信をこのコピーで開始しません。`run.bat`で文字会話を確認できます。
4. 雨衣MMDを使う場合は、[アバター導入](avatar_ja.md)の手順で利用者自身のPMXを`local/models/mmd`内へ置き、`local/avatar.yaml`の3Dを設定します。PMX・テクスチャは同梱しません。
5. 新規見本には待機ID `sample_otokam_048` と `motion_library_enabled: true` が設定済みです。3Dを有効にして互換性確認が通ると、同梱カタログの有効なモーションを既存の会話経路で使います。「設定」→「表示」→「モーションを管理」から登録・権利の状態を確認できます。

既存の`local/vmd_catalog.yaml`がある場合は、同梱素材の追加・カタログ統合・上書きを一切行いません。既存の`local/avatar.yaml`も通常のセットアップで保持します。通常環境のPMX・VMD・人格・記憶設定を置き換えません。

## 失敗・中断したとき

ハッシュ不一致、同名の異なる既存ファイル、local外への参照はエラーで止めます。配布候補と競合したファイルを自動的に上書きしません。カタログは全素材を配置した最後に作ります。途中中断で同じバイトの一部だけが残った場合は、再実行で残りを配置できます。

1. エラーが出たらセットアップを終了し、表示されたファイル名を控えます。
2. 同名ファイルの削除・素材の書換え・フォルダー権限の一括変更をしません。
3. 競合の場合は、別の新しいフォルダーへ候補を展開してセットアップします。元の環境は元フォルダーの`run.bat`から戻れます。
4. カタログができてもPMXの互換性や権利確認で止まる場合は、音声・3Dを無効にしたMock文字会話へ戻り、[復旧手順](backup_and_recovery_ja.md)を使います。

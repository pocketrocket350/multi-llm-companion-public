候補には自作ソース、テスト、スクリプト、見本設定、操作文書、ライセンスと、条件を確認した既存の物理計算DLLを含めます。Pythonと依存パッケージはセットアップ時に取得します。`.venv`、APIキー・認証情報、通常の`.env`・`local`・DB、診断生ログ、生成音声、画像、PMX・テクスチャ、Whisper/Voskモデル、VoiSona Talkとボイスライブラリは同梱しません。再配布条件を記録した採用VMD26件、4パックの原文Readme、出典・改変内容・権利YAMLを同梱します。[同梱VMD](bundled_motions_ja.md)を参照してください。

雨衣の名称やVoiSonaへの接続説明は、素材そのものの利用・再配布許可ではありません。利用者自身が正規配布元から素材・ソフトを用意し、個人利用、配信、商用利用、改変、再配布を別々に確認します。[権利表記](rights_and_credits_ja.md)と[第三者通知](../THIRD_PARTY_NOTICES.md)を参照してください。

## 1. Mock最小構成

目的はAPIキー・外部素材なしで導入、文字会話、保存、終了を確認することです。Mock最小構成は設定上の最小構成で、セットアップは既存の全依存関係を導入します。

1. Windows 11とPython 3.12を準備します。候補は新しい書き込み可能なフォルダーへ展開し、通常環境の`local`やDBを入れません。
2. `setup_windows.bat`をダブルクリックします。インターネット接続が必要です。「セットアップが正常に終わりました」を確認します。失敗時はそこで止め、[復旧手順](backup_and_recovery_ja.md#3-起動できない機能が動かないとき)を使います。
3. `run.bat`をダブルクリックします。入力欄へ「こんにちは」と書き、Enterまたは三角矢印「送信」で送ります。Mockの返答が表示されることを確認します。音声・マイク・3Dは初期状態で無効です。
4. 右上の歯車「設定」→「診断情報」でプロバイダーがMockであることを確認します。
5. 回答終了後に右上の「×」で閉じます。`run.bat`を開き直し、左上の時計「履歴」を押して先の会話を選びます。本文が戻れば保存・再開成功です。

画面が開かない、返答が出ない、履歴が戻らない場合は失敗です。繰り返し送信せず、表示されたエラーと操作番号を控え、アプリを終了します。元の環境は元フォルダーの`run.bat`から再開できます。

## 2. 現在採用する基準完全構成

基準はOpenAI互換の公式API・`gpt-6-luna`、HTTP/2接続再利用、採用済み検索・画像会話・人格・記憶、雨衣のVoiSona Talk実音声、採用した音声認識・マイク、雨衣PMXと利用条件確認済みのローカルVMDです。現在の通常設定、人格・記憶の指示順序、訂正処理を配布準備で変更しません。

新しいPCでは次を個別に準備します。通常PCの受入を取り消すための再試験ではなく、新しい導入先固有の接続確認です。Codexは今回有料API要求を実行していません。新たなCodexによる有料試験は別の事前承認が必要です。

1. 先にMock手順を終えます。新PC用の`local`を [LLM設定](providers_ja.md)、[音声](audio_ja.md)、[アバター](avatar_ja.md)、[VMD登録](vmd_catalog_ja.md) の手順で設定します。APIキー・VoiSonaの資格情報はWindows環境変数から渡します。
2. VoiSona Talkと正規のボイスを準備し、必要なAPI接続を有効にします。音声認識モデルとマイクを導入します。モデル・VMD・ライセンス記録は利用者用`local`へ置きます。再配布可否が不明な素材を候補へ追加しません。
3. `run.bat`で起動し、「設定」→「診断情報」でモデル名、認識、音声出力、3Dの状態を確認します。「設定」→「会話・音声」→「LLM接続・マイクの設定」で採用した入力機器を選びます。勝手に別ボイスや別モデルへ切り替えません。
4. 新しい導入先で行う実APIの通常利用は、そのサービスの料金と利用上限を利用者自身が確認してから行います。設定だけの確認と実API会話、実音声・実マイクの確認を分けて記録します。
5. 終了・履歴再開・個人用バックアップの復元は [バックアップと復旧](backup_and_recovery_ja.md) を使います。

新PCで音・マイク・描画・保存に問題があれば、必要な機能を止めてMock文字会話へ戻り、操作番号と診断状態を記録します。素材・DBの削除や権限の一括変更は行いません。

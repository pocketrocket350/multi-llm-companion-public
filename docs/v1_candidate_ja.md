# 対応環境と既知の制限

## 環境と同梱内容

Windows 11・Python 3.12 x64向けのソース版です。Python 3.12 x64を事前に用意し、アプリに必要なパッケージはセットアップ時に導入します。**クリーンなWindows環境や別PCでの導入は未確認**です。現PC内の隔離フォルダー・仮想環境での確認とは区別しています。

ソース、設定見本、利用ガイド、物理計算DLL、出典・原文規約付きVMD26件を含みます。PMX・テクスチャ、VoiSona Talk本体・ボイス、認識モデル、個人設定・会話・秘密情報は含みません。

## 既知の制限

| 項目 | 制限 |
| --- | --- |
| 応答待ち時間 | 現PCの通常会話開始の測定値は中央値2.689秒、95%点3.634秒。目標1.5秒・2.5秒は未達で、最大値は4.325秒から4.688秒へ増加。通信やAPI側の待ちもある |
| 衣装物理・長時間利用 | 布が安全範囲から外れた過去の異常と、一部の試験の終了記録欠落が残る。後続診断では再現せず、原因は未特定 |
| MMD | 基準PMX向けの表情・動作設定。別版・別モデルではモーフや体格への調整が必要 |
| 画像の続きの質問 | 既出の説明文を引き継ぐ。新しい細部を尋ねるには画像の再添付が必要 |
| 記憶 | 保存・訂正・検索の自動判断は完全ではない。管理画面で確認・修正できる |
| 検索・画像共有 | OpenAI公式APIと対応モデルが必要。別のモデルへ自動変更しない |
| 依存パッケージ | v1.1.1もv1.0.1と同じ依存版を使用し、指定版を取得できない場合は停止する。Python本体・外部サービス・音声やモデル素材は固定対象外。詳細は [配布ファイルと導入](release_ja.md) を参照 |

自動テスト、隔離環境の統合確認、実音声・実マイク・見た目の確認はそれぞれ対象が異なります。全機器・全会話・長時間動作の保証ではありません。配布ファイルに添付する `VERIFICATION.json` に実施範囲を記録しています。

## 素材の利用条件

同梱VMDの4パックは、2026年10月15日に公式配布ZIP内のReadmeとの一致を確認済みです。原文・出典・補正内容と利用条件は [同梱VMD](bundled_motions_ja.md) を参照してください。PMX・音声・使用ソフトの条件は別に適用されます。

導入は [初心者ガイド](beginner_guide_ja.md)、不具合時の停止・復帰は [復旧手順](backup_and_recovery_ja.md) にあります。

# バックアップと復旧

アプリを終了してから、ファイルコピーで保存・復元します。バックアップには会話・個人設定・秘密情報が含まれるため、個人用の場所へ保存してください。

## 保存するもの

| 内容 | 既定の保存先 |
| --- | --- |
| 会話・画像プレビュー・記憶・感情 | `data/conversations.db` |
| 設定・PMX・VMD・テクスチャ・認識モデル | `local` フォルダー |
| 画面サイズや操作の好み | Windowsの設定（下記の書き出しが必要） |
| 接続用の秘密情報 | Windows環境変数、使用している場合は `.env` |

`local/app.yaml` の `database_path` を変更した場合は、そのDBを保存します。`local` 外の素材や画像の元ファイルも別に保存してください。ソフトの契約・ボイスライブラリ・環境変数はフォルダーコピーだけでは移りません。`.venv` は移植せず、新しい場所でセットアップします。

## バックアップする

1. 生成・録音・読み上げを終えるか、表示中の取消・停止ボタンで止め、右上の **×** で終了します。画面と起動元のコマンド画面が閉じるまで待ちます。
2. アプリの外へ、日付などを付けた新しいバックアップフォルダーを作ります。
3. `local` と `data` を **コピー** します。DBの隣に `-wal`・`-shm` が残っている場合も一緒にコピーします。
4. `.env` を使っている場合は個人用バックアップへコピーします。Windows環境変数の秘密値は文書や報告へ転記せず、安全な管理先から再設定できるようにします。
5. コピー先に設定ファイルとDBがあることを確認します。既存バックアップへ上書きしません。

終了できない状態のDBを通常のファイルコピーで保存しないでください。

### 画面の好みも保存する場合

バックアップフォルダーのアドレス欄へ `cmd` と入力してEnterを押し、次を実行します。

```bat
reg export "HKCU\Software\multi-llm-companion\desktop-companion" "window-settings.reg"
```

**この操作を正しく終了しました** と表示され、`window-settings.reg` ができれば完了です。キーがない場合は画面設定を省略できます。上書き確認が出たら中止し、別のフォルダーを使います。

## 新しいフォルダーへ復元する

1. 元のアプリを終了します。ソースZIPを別フォルダーへ展開し、`setup_windows.bat` を完了します。
2. 復元先にある `local`・`data` を `local-before-restore`・`data-before-restore` へ名前変更します。同名の退避先があれば別名を使います。
3. バックアップの `local`・`data` をコピーします。独自の `database_path` や素材の絶対パスは、元の環境ではなく復元先を指すよう直します。
4. `.env` が必要なら、復元先の既存ファイルを別名へ退避してからコピーします。外部AIを呼ばずに確認する場合は、復元先の `local/app.yaml` だけを `active_provider: mock` にします。
5. 復元先のフォルダーのアドレス欄で `cmd` を開き、次を順に実行します。保存先を指定する環境変数を、このコマンド画面の中だけで外して起動します。

```bat
set "MULTI_LLM_COMPANION_HOME="
run.bat
```

6. **履歴** で会話、**設定 → 会話・音声 → 記憶を管理** で保存した記憶を確認します。
7. 新しい会話を保存して終了し、同じ方法で再起動します。追加分も履歴へ残れば復元完了です。

画面の好みも戻す場合だけ、すべてのアプリを終了した状態で、バックアップフォルダーのコマンド画面から `reg import "window-settings.reg"` を実行します。**同じWindows利用者の全アプリコピーへ共通で反映されます。** 戻す前に現在の値も別フォルダーへ書き出してください。バックアップにない後発設定は削除されません。

破損・履歴欠落・別DBへの保存があれば復元先での利用を止め、元フォルダーの `run.bat` へ戻ります。元DBやバックアップは削除しません。画面設定を戻した場合は、事前に書き出した現在の値を同じ方法で戻せます。

## 起動や接続で困ったとき

| 症状 | 対処 |
| --- | --- |
| Pythonが見つからない | Python 3.12を導入し、起動するフォルダーを開き直す |
| セットアップが失敗する | エラーに従ってネット接続、空き容量、フォルダー・TEMPの書込み権限を確認する |
| `.venv` のPython版が違う | 終了後に `.venv` を別名へ退避し、セットアップをやり直す |
| 設定ファイルがない | セットアップで不足する見本を作る。既存の誤設定は自動修正されない |
| YAMLのエラー | エラーに出たファイルの直前の編集を戻す。空白・コロン・引用符を確認する |
| API認証・接続エラー | [LLM設定](providers_ja.md)を確認。`active_provider: mock` で文字会話へ戻せる |
| 音声・マイク・MMDが動かない | [音声](audio_ja.md)・[アバター](avatar_ja.md)の設定と素材の配置を確認する |
| 履歴を保存・読込みできない | 元DBを保ち、上の手順で別フォルダーへ復元する |

解決しない場合は操作とエラーを控え、秘密値・会話本文を除いて報告します。権限の一括変更や素材・DBの削除で回避しないでください。

# 感情状態

LLMの回答に含まれる感情情報を、会話ごとの「現在の感情」として表示します。第43段階では、この状態を音声、表情、視線、ジェスチャー、自然動作へ整合して渡します。

## 画面の見方

画面上部の「感情」には、通常、喜び、悲しみ（心配に相当）、怒り、照れ、驚きのいずれかと強さが表示されます。強さは0から100%の入力状態です。

感情は回答のたびに急に切り替わらないよう、前回の状態を少し残して変化します。画面の`表現統合`には、その平滑化後の状態から実際に作った音声・表情・動作・視線・自然動作の値と、無効・安全補正・未対応が表示されます。

## 第43段階の出力別変換

入力の`emotion_intensity`を全出力へ同じ倍率で流しません。`ExpressionPolicy`が一度だけ、出力ごとの曲線、感情別係数、次の最大値を適用します。

- VoiSona話速・抑揚用の音声強度: 0.55
- PMX表情モーフ: 0.82
- ジェスチャーまたは会話VMD: 0.68
- 視線: 0.50
- 自然動作へ渡す会話感情: 0.32

neutralは強度にかかわらず感情表現値を0にします。happy、sad、angry、embarrassed、surprisedはそれぞれ別の係数を使います。強度0、弱、中、最大でも上限を超えないことを自動テストで確認しています。

音声表現は設定で無効にできます。無効時は音声専用値を0として`無効`と表示しますが、表情、視線、動作、自然動作は引き続き一つの計画から作ります。VoiSonaの設定詳細は`docs/audio_ja.md`を参照してください。

## 整合性と診断

通常経路では、一つの平滑化済み感情から全出力を再計算するため、「音声だけ喜び、表情だけ悲しみ」のような感情方向の分裂を自動的に防ぎます。未対応ジェスチャーは`none`、未対応視線は`forward`へ安全補正し、状態欄へ表示します。

外部・将来実装から別々の感情チャンネルが渡された場合に備え、強度0.35以上で正負の感情方向が衝突した場合だけ診断します。弱い表現、neutral、無効な出力は矛盾として誤検出しません。モデル固有モーフの意味が設定と合っているかは自動判断せず、PMX状態表示と利用者の見た目確認に残します。

## 保存と削除

感情状態は会話ごとにSQLiteへ保存されます。同じ会話を開き直すと、最後の感情状態を表示し、その時点の設定で出力別の値を再計算します。出力別の一時値や発話世代は新しい保存形式へ追加しません。会話履歴を削除すると、その会話の感情状態も一緒に削除されます。

感情状態は利用者の個人情報や長期記憶ではありません。感情から記憶候補を作ったり、人格設定や長期記憶を変更したりはしません。

## 未対応

- ボイスごとに種類・数・順序が異なるVoiSonaの`style_weights`
- PMXモーフ名の意味を見た目から自動推定すること
- 感情による人格設定や長期記憶の変更

第43段階は、代表状態、上限、無効設定、弱い表現の誤検出防止、割り込み世代を自動確認済みです。利用者は音声表現を無効にした従来動作と、有効時の実VoiSona・PMX画面の状態表示を確認し、第43段階を受け入れ済みです。

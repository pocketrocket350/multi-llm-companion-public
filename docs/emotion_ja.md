# 感情表示

**設定 → 診断情報** の **感情** で、現在の感情と強さを確認できます。LLMの回答に含まれる情報を使い、急に切り替わらないよう前回の状態も反映します。

**表現統合** には、音声・表情・動作・視線などへ適用した値と、無効・未対応の状態が表示されます。すべてへ同じ強さを適用するのではなく、出力ごとに調整しています。

音声の感情表現は既定では無効です。有効化は [音声ガイド](audio_ja.md#口パクと声の表現)、表情の対応は [アバター](avatar_ja.md) を参照してください。ボイス固有の `style_weights` と、見た目からPMXモーフの意味を自動判定する機能はありません。

感情は会話ごとに保存され、履歴を再開すると戻ります。その会話を削除すると感情状態も消えます。感情表示によって人格設定や長期記憶を書き換えることはありません。

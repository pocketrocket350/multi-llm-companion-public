# 画面から接続情報を設定する

APIキーやパスワードを、アプリの画面で入力できます。従来の環境変数方式も利用でき、初期状態は **環境変数で設定** がオンです。環境変数やPythonの操作を覚える必要はありません。

## 初回の操作

1. `setup_windows.bat` を完了して **起動** ショートカットを開きます。最初は **mock**（外部通信なしの動作確認）なので、APIキーは不要です。
2. 右上の歯車 **設定 → 環境設定 → LLM・VoiSona Talkの接続設定** を開きます。
3. **環境変数で設定** のチェックを外します。**保存する方式: 画面入力** と表示されます。
4. **使用するLLM接続先** で利用するサービスを選び、そのサービスが発行した **APIキー**、案内された **接続先URL**、**モデル名** を入力します。接続先の選択と入力はこの一画面で保存します。
5. 読み上げを使う場合だけ **VoiSona Talkで読み上げる** をオンにします。VoiSona Talk本体でREST APIを有効にし、そこで設定した **ユーザー名・パスワード** を入力します。**ボイス一覧から選ぶ → 使う名前を選択 → 選択** でボイス名を反映できます。購入用アカウントのパスワードは入力しません。**接続先URL** は通常初期値のままです。詳しくは [音声のガイド](audio_ja.md)。
6. **保存（再起動後に反映）** を押します。不足があると画面下部に直す項目が表示されます。修正して再度保存してください。**キャンセル** または右上の **×** では保存しません。
7. 保存完了の案内を閉じ、アプリを右上の **×** で終了して、**起動** から開き直します。保存しただけでは接続テストや外部送信は行いません。
8. **設定 → 診断情報** のプロバイダーとモデルが、選んだ接続先に変わっていることを確認し、文章を送信します。マイクは **設定 → 音声 → マイクの設定** で別に調整できます。

**環境設定** の上部には、今動いているアプリが使っている方式が表示されます。チェックボックスと **保存する方式** は次回起動に使う方式です。保存後も再起動までは現在の接続情報を使います。

**使用するLLM接続先** は環境変数方式でも選べます。環境変数方式では、APIキーなどの入力欄は使いません。接続先の選択だけでも、反映は保存後の再起動です。設定全体の項目分けは [設定画面の案内](settings_ja.md) を参照してください。

## 保存前に接続を確認する

1. **設定 → 環境設定 → LLM・VoiSona Talkの接続設定** を開きます。
2. **環境変数で設定** のチェックを外し、試したい接続先を選んで **接続先URL・APIキー・モデル名** を入力します。追加したばかりの接続先や、まだ保存していない変更も試せます。
3. 上部の **接続テスト** を押します。短い固定文を1回送るため、提供元の料金が発生する場合があります。会話履歴・人格・記憶・音声情報は送りません。
4. **接続テスト中です** の後、同じ画面の上部に結果を表示します。**接続テスト成功** は、入力した接続先とモデルで確認用の応答が返った状態です。テストだけでは設定を保存しません。
5. 成功後、この接続先を使うなら **保存（再起動後に反映）→終了→起動** と操作します。試すだけなら **キャンセル** で閉じます。

環境変数方式で **接続テスト** を押すと、その接続先が参照する環境変数の値だけで確認します。無効になっている画面入力の値は使いません。`mock` は外部通信をしないため、接続テストは使えません。VoiSona Talkには、下記の専用の **接続テスト・試聴** ボタンを使います。

失敗した場合は日本語で直す項目や理由を表示します。未入力なら不足する項目、HTTP 401ならAPIキー、403なら利用権限、404ならURLまたはモデル名、429なら利用枠や混雑を確認してください。通信できない場合はURL・ネット接続・プロキシ、証明書エラーではURL・PCの日時・通信環境を確認します。エラーの生本文や、キーを含む可能性がある接続先からの文面は表示・記録しません。転送先へ認証情報を渡さないため、別URLへの転送が返った場合も停止します。提供元の正式なAPIのURLを入力してください。

テスト中も入力の変更やキャンセルができます。入力・方式・接続先を変えると、古いテスト結果は使いません。終了後にもう一度テストしてください。画面を閉じても送信済みの要求は取り消せない場合があります。接続・読み取りの待ち時間は最大15秒ずつに制限し、自動で再送しません。

この確認は短い文章への応答だけを調べます。通常の会話のストリーミング、Web検索・画像共有、音声・MMDの動作までは保証しません。通信には専用のHTTP/1.1接続を使い、通常の会話用接続や設定を変更しません。失敗が続くときはテストの繰り返しを止め、**キャンセル** で保存前の状態へ戻してください。報告するときは日本語の結果と操作順だけを伝え、APIキーやパスワードは含めないでください。

## ボイス名を一覧から選ぶ

1. 同じPCでVoiSona Talkを起動し、使うボイスを導入してREST APIを有効にしておきます。
2. **設定 → 環境設定 → LLM・VoiSona Talkの接続設定** を開き、**環境変数で設定** のチェックを外します。下へスクロールし、**VoiSona Talkで読み上げる** をオンにします。
3. **接続先URL・ユーザー名・パスワード** を入力します。ボイス名はまだ空欄で構いません。
4. 音声欄の下の **ボイス一覧から選ぶ** を押します。保存前の3項目で導入済みボイスを取得し、選択画面を開きます。この操作では合成・再生・設定保存を行いません。
5. 一覧を開いて使う名前を選び、**選択** を押します。元の画面の **ボイス名** に反映されます。現在の名前が一覧にあれば、その名前を初期選択にします。一覧にない場合も、**選択** を押すまでは元の名前を変更しません。
6. 必要なら **VoiSona Talkの接続テスト・試聴** で声を確認し、使う場合だけ **保存 → アプリ終了 → 起動** と操作します。

選択画面の **キャンセル・Esc・×** では名前を変更しません。設定画面全体の **キャンセル** は、候補から選んだ名前を含む未保存の変更を取り消します。取得に失敗した場合や一覧が空の場合も、現在のボイス名を保持して日本語の理由を表示します。URL・ユーザー名・パスワード・方式・読み上げチェックを変更すると古い一覧を使わず、開いていた選択画面も閉じます。取得を待っている間も、設定画面は閉じられます。

一覧選択は **画面入力方式** で使います。環境変数方式ではボタンが無効になり、既存の環境変数や `.env` を変更しません。従来の手入力・保存済みのボイス名・環境変数方式の一覧コマンドも引き続き使えます。同じ名前の複数バージョンは、既存の保存形式に合わせて1件にまとめます。

HTTP 401ならAPI用ユーザー名・パスワード、404ならURL・ポート、接続できない場合はVoiSona Talk本体とREST APIの起動を確認してください。失敗が続けば **キャンセル** で保存前に戻れます。報告には操作順と日本語の結果だけを記載し、パスワードや認証ヘッダーは含めないでください。

## 保存前にVoiSona Talkを試聴する

1. このPCでVoiSona Talkを起動し、使うボイスを導入してREST APIを有効にしておきます。詳しくは [音声ガイド](audio_ja.md#voisona-talkの声で読み上げる) を参照してください。
2. **設定 → 環境設定 → LLM・VoiSona Talkの接続設定** を開き、**環境変数で設定** のチェックを外します。
3. 下へスクロールし、**VoiSona Talkで読み上げる** をオンにして、**接続先URL・ユーザー名・パスワード** を入力します。**ボイス一覧から選ぶ** でボイス名を選択します。従来の手入力も可能です。VoiSona Talk側のAPI用設定を入力し、購入用アカウントのパスワードは使いません。パスワードは伏せ字です。
4. 音声欄の下にある **VoiSona Talkの接続テスト・試聴** を押します。保存前の入力で認証とボイス名を確認し、固定文「こんにちは。音声のテストです。」を1回だけ合成して、このPCの既定の音声出力で再生します。LLM・会話履歴・人格・記憶は使いません。
5. ボタンの下に **接続を確認 → 音声を合成 → 再生中 → 再生が終了** の順で状況を表示します。接続確認だけで音が出たとは判定しません。最後に指定した声が聞こえたら試聴の確認完了です。
6. 採用するなら **保存（再起動後に反映）→アプリ終了→起動** と操作します。試聴だけでは設定を保存しません。確認だけなら **キャンセル** で閉じます。読み上げを保存せず試す場合は、試聴後にチェックを戻すかキャンセルしてください。

環境変数方式でも同じボタンを使えます。この場合は、既存の音声設定のURLと、その設定が参照する環境変数のユーザー名・パスワード・ボイス名だけを使います。画面入力の値は補完に使いません。読み上げがオフでも、接続情報がそろっていれば、この明示的な操作で試聴できます。保存した有効・無効の設定は変えません。

**試聴を停止** は音声を止め、今回の合成要求だけを片付けます。入力・方式・読み上げチェックの変更、保存、キャンセル、×でも試聴を停止し、古い結果を表示・再生しません。通信待ちの要求は応答を待ってから片付けるため、停止処理中でも画面を閉じられます。送信済みの合成は取り消せない場合があります。試聴用WAVは一時領域に作り、終了時に削除します。再生後の後片付けの通信に失敗した場合は、再生終了と区別して「後片付けを確認できませんでした」と案内します。停止・画面終了・通信切断時も含め、VoiSona Talk側に今回の受付情報が残る場合は本体の状態を確認してください。会話履歴やバックアップには試聴や認証情報を保存しません。

失敗時は直す内容を日本語で表示します。HTTP 401はAPI用ユーザー名・パスワード、403はAPIの権限、404・405はURL・ポートを確認します。ボイス名が見つからない場合は別の声へ切り替えません。合成に失敗した場合はボイス・言語・本体の状態を確認してください。音声ファイルを読めない場合は、VoiSona Talkと同じPCで動かしていることと一時保存先の書き込み権限を確認します。再生できない場合や再生終了の表示でも聞こえない場合は、Windowsの既定の出力機器・音量・ミュートを確認してください。

接続・読み取りの待ち時間は15秒以下、合成の待ち時間は30秒、再生の監視は20秒を基準にしています。試聴音声は15秒以内・4MiB以下に限ります。音声表現・口パク・MMDはこの試聴の対象外です。失敗が続く場合は **試聴を停止 → キャンセル** で保存前に戻してください。報告には操作順と日本語の結果だけを記載し、パスワードや認証ヘッダーを含めないでください。

## 接続先を追加・編集する

OpenAI互換のChat Completions APIを使うサービスは、YAMLファイルを編集せずに追加できます。URL・モデル名・APIキーは提供元の案内で確認してください。Web検索・画像共有は任意の互換サービスで自動的に利用できるものではありません。

1. **設定 → 環境設定 → LLM・VoiSona Talkの接続設定** を開きます。
2. **環境変数で設定** のチェックを外します。
3. **接続先を追加** を押し、一覧に表示する名前（例: 仕事用AI）を入力して確定します。既存と重なる名前や空欄では追加できません。名前欄にAPIキーは入力しません。
4. 追加した名前が **使用するLLM接続先（再起動後）** に選ばれます。**接続先URL・APIキー・モデル名** を入力します。音声設定は必要な場合だけ変更してください。
5. **保存（再起動後に反映）→アプリを終了→起動** の順に操作します。**設定 → 診断情報** に追加した名前とモデルが表示されます。

既存の接続先を編集するときは、一覧でその名前を選んでからURL・APIキー・モデル名を変更します。呼び名だけを変えるには **名前を変更** を押します。名前を変更しても、登録済みの接続情報や既存の環境変数名・回答の長さ・待ち時間の設定は引き継ぎます。`mock` の名前は変更できません。

追加・名前変更・入力内容は、最後の **保存** を押すまでファイルへ書き込みません。**キャンセル** または **×** でまとめて取り消せます。名前を入力する小画面のキャンセルは、その名前の追加・変更だけを取り消します。保存に失敗した場合は入力を保持し、通常は接続先一覧・選択・認証情報を前の状態へ戻します。他の場所で一覧が変更されたという表示が出た場合は、キャンセルで閉じて開き直してください。復元にも失敗したという表示が出た場合は再起動を止め、編集画面を閉じずに保存先の権限を確認してから、保存をやり直してください。

追加と名前変更は画面入力方式で行います。環境変数方式に切り替えると、使用する環境変数の **名前だけ** が表示されます。追加した接続先にも専用の参照名を自動で割り当てますが、Windowsの環境変数や `.env` は作成・変更しません。環境変数方式で使う場合は、表示された名前の環境変数を自分で登録してください。画面入力の値は環境変数方式では使わず、保護したまま残します。

新しい接続先の回答のばらつきは0.7、出力上限は1024トークン、待ち時間は60秒です。既存の接続先の詳細設定は変更しません。OpenAI互換でないAPIには専用の接続処理が必要です。

既にAIを選択していて、環境変数が未設定などの理由で会話画面を開けない場合は、起動時に直接 **環境設定** が開きます。そこで「初回の操作」の手順3〜6を行い、案内に従ってもう一度起動してください。会話DBを開く前に設定するため、この導入操作だけで会話は作成されません。

## 接続先と保存済みAPIキーを削除する

1. **設定 → 環境設定 → LLM・VoiSona Talkの接続設定** を開きます。
2. **使用するLLM接続先（再起動後）** で削除したい名前を選び、**接続先を削除** を押します。削除は環境変数方式・画面入力方式のどちらでも使えます。
3. 確認画面で **削除する名前** と **削除後の接続先** を確認します。初期選択は **キャンセル** です。やめる場合はキャンセル・Esc・×で閉じてください。
4. 対象が正しければ **削除を予約** を押します。この時点ではまだ保存しません。別の接続先が選ばれ、削除予約の案内が表示されます。
5. **保存（再起動後に反映）** を押します。接続先定義と、それに対応するAPIキー・URL・モデル名を保護ストアから削除します。他の接続先やVoiSona Talkのパスワードは保持します。編集画面の **キャンセル** または **×** なら、削除予約を含む未保存の変更を取り消せます。
6. アプリを終了して開き直します。**設定 → 診断情報** で代わりの接続先を確認できます。削除した名前は接続先一覧に表示されません。

使っていない接続先だけを削除した場合は、元の使用する接続先を維持します。元の接続先そのものを削除した場合は、通常は外部通信しない **mock** へ切り替えます。mockがない独自構成では、残る接続先を確認画面に表示します。保存前に一覧で選び直せます。残る接続先の入力が足りなければ、画面の指示に従って入力してください。復旧用のmockと、最後に残った1件は削除できません。

保存後は、現在の保護ストアを削除対象の情報を含まない内容で暗号化し直します。削除したAPIキーを平文の一時ファイルやバックアップへ移しません。起動中のアプリは再起動まで以前の接続設定を保持するため、削除を終えたらアプリを開き直してください。Windowsの環境変数・`.env`や、提供元に登録されたAPIキー自体を削除・失効させる操作ではありません。過去に自分で作成したバックアップやストレージ上の古い暗号データを復元不能に消去する機能も含みません。

保存に失敗した場合、通常は削除前の接続先と保護済みキーを残し、画面には削除予約を保持します。保存をやり直すか、キャンセルしてください。復元にも失敗した案内では再起動を止め、編集画面を閉じずに保存先の権限を確認してから、保存をやり直してください。保存済み情報が読み出せない場合は削除ボタンを使えません。既存の環境設定を復旧してから開き直してください。他の場所で接続情報が変更された場合も、削除を保存せず開き直す案内を表示します。

復元失敗後に画面を閉じ、次の起動で使用する接続先が一覧に見つからない場合も、環境設定が開きます。mockなど残る接続先を選び直して保存すると起動を復旧できます。ただし、これは失敗した削除の完了ではなく、保護済みキーが残る場合があります。削除は、元の編集画面で保存が成功したことを確認して完了してください。

## 保管とバックアップ

- APIキーとパスワードは伏せ字で表示します。入力した情報と設定方式をまとめてWindows標準のDPAPIで暗号化し、`%LOCALAPPDATA%\multi-llm-companion\connections` のアプリ配置場所ごとの領域へ保存します。通常のYAML・JSON・QSettingsへ平文保存しません。Windowsの同じ利用者が復号できる保護方式です（[Microsoftの仕様](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)）。
- プロジェクト内に認証情報のファイルを作りません。接続先の名前と環境変数の参照名など、秘密値を含まない定義は既存の接続先YAMLへ保存します。`local`・`data`・画面設定のバックアップやソースの配布物には、画面入力の認証情報を含めません。上記の個人用保管フォルダーをバックアップや配布物へ追加しないでください。
- 別PC・別Windows利用者・別フォルダーへ移動や復元をした場合は、接続情報を再入力してください。コピー先へ認証情報を自動で引き継ぎません。
- Windows環境変数と `.env` は、自動で変更・削除しません。従来方式で自分が作成した `.env` の秘密情報は、別途管理してください。
- 設定欄の値は会話履歴や記憶へ送りません。APIキーやパスワードをチャット、エラー報告、画面写真へ転記しないでください。

## 失敗した場合と元に戻す方法

保存に失敗した場合は画面を閉じずに入力を保持し、前回保存した方式と値を残します。空き容量や保存先の権限を確認してから保存し直すか、**キャンセル** で閉じてください。

読み出せない場合は、起動時の環境設定で再入力して保存できます。別のWindows利用者で開いている場合は、元の利用者へ戻してください。会話DBや素材を削除する必要はありません。

従来方式へ戻す場合は **環境設定 → 環境変数で設定をオン → 保存 → 終了 → 再起動** の順です。保存した画面入力の値は保護したまま残り、環境変数方式では使いません。環境変数の値へ部分的に補完することもありません。

# 読み取り専用調査の委任

`AGENTS.md`の条件で委任するときに読む。

- 親は要件解釈、アーキテクチャ、設計変更、実装・修正、大規模リファクタリング、セキュリティ・互換性、最終判断・確認・報告を担当する。
- `luna_worker`には独立した調査範囲を指定する。対象はファイル・関数・クラス・設定・文字列の所在、重複・欠落・表記揺れ・命名不一致の照合、ログ・エラー・テスト結果、実行経路・影響範囲、資料と実装の不一致、親の仮説の事実確認。
- 子は読み取り専用。ファイルの編集・作成・削除は委任しない。
- 1～2ファイルで済む、準備の方が重い、文脈分割で精度が落ちる、利用者が禁止した場合は親が行う。同じ調査を重複委任せず、速度・精度に実益がある場合だけ使う。
- 結果は確認済み・推測・不明・親が判断する事項を分け、可能な限りパス、関数・クラス名、該当箇所を示させる。親は重要な根拠を確認してから修正・最終報告へ使う。

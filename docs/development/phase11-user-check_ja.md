## 起動前と画面だけの確認

2026-09-24更新：表示範囲、音声操作3項目、Web検索・画像送信の許可を変更すると保存し、再起動後も維持します。初回の既定値はバストアップ、音声操作3項目はオフ、Web検索・画像送信はオンです。以前の版で保存していなかった項目は、更新後に一度選び直してください。復元だけでは録音や送信を始めません。[変更・検証・戻し方](settings-persistence_ja.md)。

1. 起動中の旧画面があれば、処理中の取消／停止を押し、通信や生成の終了を待って右上の「×」で閉じます。履歴や設定ファイルは削除しません。
2. エクスプローラーで `<project-root>` を開き、`run.bat` をダブルクリックします。通常の会話・設定を使うアプリです。検証専用の架空会話は入りません。
3. 左側に雨衣と床付きの水色の部屋、右側に会話と入力欄が出ます。初回はバストアップで、保存済みの選択があればそれを使います。全身／バストアップはモデル表示部右上の人物アイコンで切り替えます。全身の縮小は、表示領域の高さに全身が収まる標準サイズで止まります。
4. 左上の「履歴」を押すと会話一覧・「新しい会話」・「この履歴を削除」が開きます。もう一度「履歴」を押すと閉じます。削除ボタンを試す必要はありません。過去の返答や出典も会話側に表示します。
5. 履歴とモデルの間、モデルと会話の間の水色の境界を左右にドラッグして幅を調整できます。幅は次回起動時も保持します。狭い画面では入力・停止に必要な最小幅が優先されます。履歴が不要なら三本バーでもう一度閉じます。
6. 雨衣の上を左右へドラッグすると、標準で正面から左右180度まで回転します。上下には傾きません。右上の歯車→「表示」→「モデルを横方向へ続けて回転できるようにする」をオンにすると、境界を越えて何周でも回せます。背景は回転・呼吸・動作では動かず、拡大縮小と注視点だけを人物へ合わせます。
7. 右上の歯車「設定」を押します。「会話・音声」には「LLM接続・マイクの設定」「人格を編集」「記憶を管理」「能動的な話しかけ」があります。「表示」に「雨衣を正面に戻す」、最前面、連続回転、表情・モーション管理、「診断情報」にモデル名・トークン・描画情報があります。設定の「閉じる」で会話へ戻れます。最前面をオンにしても、設定・管理画面を続けて操作できます。

ここまでは新しいLLM要求を送りません。履歴表示・設定開閉・ウィンドウサイズ変更だけで画面を見られます。履歴と設定を閉じた待機中には、診断一覧や無効な停止ボタンが残らないのが正常です。

## 記憶と表情を管理する

設定・管理画面は右上の最大化ボタン、またはタイトルバーのダブルクリックで広げられます。小さい画面ではスクロールして続きを見られます。

1. 「設定」→「会話・音声」→「記憶を管理」で、左に記憶一覧、右に内容と分類が表示されます。検索欄で絞れます。1件を選ぶと右側で内容を編集でき、「修正を保存」で反映します。
2. Ctrlを押しながらクリックすると複数件、Shiftを押しながらクリックすると範囲を選べます。選択件数が一覧の上に出ます。複数選択中は個別編集を無効にし、「選択した候補を承認」または件数付きの削除が使えます。削除は不可逆なので、画面確認だけなら押す必要はありません。
3. 「設定」→「表示」→「表情を管理」を開きます。「表情を選ぶ」の一覧で行をクリックすると、管理画面の左にいる雨衣へすぐ反映されます。編集へ移す必要はなく、選択だけでは保存されません。
4. 「編集」「複製」「新しく作る」で「表情を編集」へ移ります。下までスクロールすると保存名、会話で使う場面、保存ボタンがあります。見るだけの確認なら保存せず、「プレビューを終了」または「閉じる」で通常の目元へ戻れます。
5. 「モーションを管理」を開くと、左に全身が表示されます。一覧を選ぶと一度再生し、終わると通常の待機へ戻ります。もう一度見るときは「プレビュー再生」、途中で止めるときは「プレビュー停止」です。「閉じる」で元の画角・ズームへ戻ります。技術的な項目は「選んだ動きの詳細」を押したときだけ表示します。「会話・待機で使用する」は保存設定なので、動きを見るだけなら変更不要です。
6. モーションで「使用しない」「利用不可」、表情で「使用しない」「対応するモーフが不足」の行は薄い文字になります。設定変更や内容確認のため選択はできます。使用しない設定でも、素材が利用可能ならプレビューできます。
7. 「設定」→「会話・音声」→「人格を編集」で話し方などを変更できます。「保存」で次の会話へ反映し、再起動後も保持します。「キャンセル」や右上の×だけなら保存しません。画面の読みやすさを見るために人格や記憶を変更・削除する必要はありません。

表情・視線の単発テスト、自然待機VMDの生成、VMDカメラ・照明、動きを表示するチェック、状態を隠すボタンは通常設定から撤去しました。詳細は[設定整理の変更・検証記録](settings-ux-refinement_ja.md)にあります。

## 普段の会話で確認する場合

1. 必要なら「履歴」→「新しい会話」を押します。右下の入力欄へ「今日はここで少し休もうかな。」と入力し、「送信」またはEnterを押します。通常設定のLLMを使うため、通常のAPI料金が発生します。過去の評価予算枠は使いません。
2. 自分の文は右寄せの緑、雨衣の返答は左寄せの白になります。発言脇に時刻、日が変わる箇所に日付が出ます。古い履歴で時刻不明のものには日時を付けません。日時・出典の説明・内部項目はセリフへ混ぜません。入力欄のフォーカス時に選択中のIMEをオンにし、その後の手動オフは尊重します。変換中のEnterは確定用、確定後のEnterは送信、Shift+Enterは改行、Tabは送信など次の操作への移動です。本文は選択してコピーでき、出典リンクも使えます。
3. 生成中や読み上げ中は、入力欄の上に状態と「音声・動作を停止」が出ます。押すと、生成途中の返答・音声・口形・表情・視線・動作の古い適用を止めます。送信済みAPIの通信や料金を取り消す操作ではありません。確定済みの返答は履歴に残ります。
4. マイクを使う場合は、入力欄右側のミント色のマイクマークを押します。録音中の表示と音量が入力欄の上に出て、同じボタンが停止の四角に変わります。もう一度押すと録音を止めます。既存の自動送信・連続音声設定は「設定」→「会話・音声」で確認できます。今回の画面確認のために連続音声を有効にする必要はありません。
5. 取消の終了待ち表示が消えたら、次の文を入力して会話を続けられます。画像は入力欄下のプラスでPNG／JPEG／WebPを1枚選ぶか、PCやブラウザから入力欄・主画面へドラッグ＆ドロップします。下段にサムネイルが出て、画像上の×で外せます。ブラウザがURLを渡したときは画像の配信元から取得します。AIへの共有は質問を入力して送信したときだけです。追加確認ダイアログは出ません。送った画像は履歴にも表示され、会話削除で縮小コピーも消えます。調べ物は普段の言葉で依頼します。特定の語順は不要で、対象などが足りない場合だけ会話で尋ねます。実行中だけ入力欄の上に取消が出ます。詳しい説明が必要なら「詳しく説明して」と添えます。
6. 検索や画像送信を止めたい場合は「設定」→「会話・音声」の「Web検索を許可」「画像の送信を許可」を外します。進行中の結果も破棄します。オフのまま送信しても勝手にはオンになりません。再開は同じチェックを入れます。変更はすぐ保存され、次回起動時も維持します。許可だけで自動送信はしません。

9月29日夜更新：現在のOpenAI・Luna 6では、分野を問わず普段の言葉で調べ物を頼めます。例は「東京国立博物館が10月12日に開いているか、公式サイトで確認して」。対象が足りない場合だけ会話で尋ね、答えると元の目的を含めて検索へ進みます。追加の「お願い」は不要です。実行中だけ入力欄の上に「返事を考えています」「Webで調べています」「調べた内容をまとめています」と「返答を取消」が出ます。白い吹き出しへ結果と出典、または資料不足・通信失敗・許可オフなど実際の理由が返ります。読み上げが有効なら最終発言も対象です。停止は「返答を取消」または「音声・動作を停止」。新入力や録音開始も古い処理を取り消します。終了待ちが消えれば普通の会話を続けられます。[具体的な操作・合否・復元](research-flow_ja.md)。

## 合否・停止・復帰

成功の目安は、文字や顔が見やすい、普段の会話に不要な情報が出続けない、履歴・設定・停止の位置が分かることです。800×600の論理ウィンドウとQt倍率100％／150％、出典・長文・設定・停止は隔離環境で検査しています。これは800×600物理ピクセルのモニターや全DPI構成の保証ではありません。現行の日常画面は2026-09-29に利用者受入済みです。

実音声の今回の確認は保留です。REST API有効化後と9月29日の再確認で接続は成功しましたが、設定は `TanakaSan`、接続先が返す声は `ui_ja_JP` でした。指定と異なる声へ変更・代替再生していません。Tanaka SanがAPIで利用可能になったらCodex側で短い実合成・再生・停止を再開できます。文字列を音声処理へ渡した検査や録音状態の模擬表示を、実音声・実マイク成功とは数えていません。Windows IMEでの実キー操作・聴感も今回の自動検査では未確認です。

文字が欠ける、必要なボタンが見えない、停止後に古い音声が再開する場合は停止し、追加の有料送信をせず知らせてください。「どの操作」「画面倍率・サイズ」「見え方または音の問題」の短い説明で十分です。通常の会話全文やAPIキーは不要です。

表示を動かしてしまった場合は「設定」→「表示」→「雨衣を正面に戻す」で復帰します。履歴や設定を閉じれば会話画面へ戻れます。今回のQt修正だけを戻す場合は[Qt修正の復元手順](qt-thread-lifetime_ja.md#変更ファイルと復元)を使います。別の差分は[画像履歴・ブラウザ画像](image-history-drop_ja.md)、[一般的な調べ物](research-flow_ja.md#変更ファイルと今回分だけの復元)、[9月28日の画面](phase11-finish_ja.md)、[9月29日早期の検索継続](search-continuation_ja.md)、[出典なし返答](search-no-evidence_ja.md)の記録に区別しています。古い控えで最新変更を上書きしないでください。通常DB・設定・素材を削除する必要はありません。

以前記録した前髪・照れ表情の水色の乱れは、2026-09-23の透明度合成の修正で解消しました。髪材質・原本PMX・表情設定は変更していません。背景は利用者提供原本をlocalから読み、公開配布物へ同梱していません。

9月29日更新：雨衣が「千代田区の9月の降水量を、過去の同期間と比べて調べればいい？」など具体的な検索内容を確認したら、「それでお願い」でも検索へ進みます。白い吹き出しの「調べているよ。結果が分かったらここで伝えるね。」は処理中だけの表示です。追加で「お願い」と送る必要はなく、同じ吹き出しが最終の返答へ変わります。出典を得られた場合は結果とリンク、得られなかった場合は「探してみたけれど、今回の検索では確かな資料を見つけられなかったよ」など、普段の口調で伝えます。読み上げが有効ならこの最終返答も対象です。資料が存在しないと断定したり、分からない数値を補ったりはしません。途中の返事は保存・読み上げしません。新しい入力は進行中の検索を取り消すので、結果を待つ間は入力せず、止めたいときは「検索・返答を取消」を押します。接続拒否・タイムアウトなどで処理自体が失敗した場合は、待ち返事が消えてエラーを表示します。検索開始後に処理上限で途中終了した場合は、見つからないとは言わず、処理の上限に達して検索を最後まで終えられなかったことを会話で伝えます。自動再送はしません。完了後に普通の会話へ戻れます。直前に具体的な条件を話していれば「それを調べて教えて下さい」でも検索できます。同じ天気の話題が続いている間の「今年の9月の降水量を調べて」など、地域を言い直さない明示依頼にも対象地域と同じ月の明示済み期限を引き継ぎます。新しい日付の指定を優先します。別の話題や会話を挟んだ場合、複数の地域で曖昧な場合には補いません。[最新の検査状態と操作](search-context_ja.md)。

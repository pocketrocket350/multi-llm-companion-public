| 古い記憶を別の言い方で聞く | 関連記憶のIDが候補に届いたかと、届いた後に回答へ正しく使われたかを分ける。最近の無関係記憶を100件以上混ぜ、件数・文字数の境界も見る |
| 訂正・削除・無効化・承認待ち | 古い情報を現在の事実として使わない。削除・無効化した内容や未承認の候補を再保存・再利用しない |
| 会話切替・取消・再起動 | 別会話や古い世代から誤って情報を混ぜない。保存・参照が行われていないときに「覚えている」と断言しない |

期待する事実と記憶IDを先に定義する。取得成功率・見落としたケース、訂正前情報の再利用、未保存情報の断定、候補数・文字数、検索時間を記録する。必須ケースに欠落や誤利用が残る状態を完成にしない。候補に届くことと、実LLMの自然な会話を別に評価する。

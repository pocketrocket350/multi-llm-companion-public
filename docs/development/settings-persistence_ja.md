# 設定を再起動後も維持する修正

**現行の操作位置（2026-09-28）**：全身／バストアップはモデル右上の人物アイコン、幅変更は境界ドラッグ。保存の仕組みは以下の記録を引き継ぐが、当時の「設定」内の表示範囲・表示幅の選択欄は使わない。[現行の手順](phase11-user-check_ja.md)、[今回の検証](phase11-finish_ja.md)。

2026-09-24。利用者の「設定は再起動後も維持するように修正してください」に対応する。従来は画面幅・最前面・能動会話をQSettingsへ保存していた一方、表示範囲と音声操作3項目には保存がなく、Web検索・画像送信の許可は起動中だけの状態だった。初回の既定値と毎回の初期化を分離する。

## 変更内容と採用範囲

| 項目 | 初回の既定値 | 変更後 |
| --- | --- | --- |
| 雨衣の表示範囲 | バストアップ | 全身／バストアップを保存 |
| 認識した音声を自動で送信する | オフ | オン・オフを保存 |

| 画像の送信を許可 | オン | オフにした値も再起動後に維持 |

変更時に既存のWindows利用者設定へ保存する。画面幅・最前面も変更時に保存し、ウィンドウ位置と大きさは従来どおり終了時に保存する。保存先は既存のQSettings（組織名 `multi-llm-companion`、アプリ名 `desktop-companion`）。新たなキーは `camera_view`、`voice/auto_send_recognition`、`voice/continuous`、`voice/hold_to_talk`、`web_search/enabled`、`image_sharing/enabled`。既存の保存方式を使い、新規依存・環境変数・YAML形式・DB変更はない。追加キーは今回の保持依頼の範囲とし、再承認は求めない。

未対応の接続先でも許可設定を消さない。設定を復元しただけでは録音・返答・外部送信を始めない。モーション管理の全身プレビューは一時表示であり、普段の画角を上書きしない。原本PMX/VMD・表情・視線・音声設定・会話・記憶に変更はない。

## 利用者が次に行う操作

再起動試験と停止境界はCodexで実施済みのため、同じ検査を一式繰り返す必要はない。普段の設定を反映する操作は次のとおり。

1. 起動中のアプリを右上の「×」で閉じる。処理中なら「検索・返答を取消」または「音声・動作を停止」を押し、処理の終了後に閉じる。
2. プロジェクトの `run.bat` をダブルクリックする。
3. 「設定」→「会話・音声」で音声操作3項目と「Web検索を許可」「画像の送信を許可」を希望の状態にする。「表示」で「雨衣の表示範囲」を選ぶ。以前の版で保存していなかった値は復元できないため、今回だけ選び直す。追加の保存ボタンは不要。
4. 設定を閉じて普段どおり使う。次回も同じ設定が戻れば正常。設定復元だけで録音や送信は始まらない。音声3項目は、必要なものだけオンにする。

希望と違えば同じ設定を戻す。その変更も保存される。もし再び初期値へ戻ったり、起動直後に録音・送信が始まったりした場合は停止してアプリを閉じ、項目名と起きた操作を知らせる。通常の会話本文や秘密情報の提出は不要。

# 天気の質問が検索へ進まない不具合の修正

2026-09-24。利用者はLuna 6で通常会話が動くと報告した一方、千代田区の翌日の天気を尋ねると「この会話では検索できない」と返された。これはAPIエラー表示ではなく通常の生成回答だった。

## 原因と変更

- 既存の検索判定は「調べて」「検索して」などに限られ、「明日の千代田区の天気は？」「ネットで確認できないの？」は検索経路に入らなかった。修正前の判定を通信なしで再現した。
- 天気・気温・予報の直接質問と明示的なネット確認依頼を、既存の検索経路につないだ。本文に千代田区等の行政区名が一つ明記されていれば、地域欄への再入力を不要にした。読み取れない地名は既存の地域欄を使い、現在地は取得しない。
- 対象を省略したネット確認は、直前の利用者の天気質問から、明記された地域と時期だけで検索文を作る。実際の送信文を入力欄の近くに表示する。会話全文・保存記憶・アシスタントの発言は検索側へ送らない。地域や時期が不明、複数地域、秘密情報を含む場合は補完せず具体的な入力を案内する。
- 「Web検索はできる？」のような能力質問は検索を実行しない。通常会話へ許可・接続の状態を渡し、「まだ検索していない」と「機能を利用できない」を区別させる。APIの成功までは保証しない。過去の誤った可否説明より現在の状態を優先する。
- 引用文・検索しない指示・普通の会話・能動会話を検索要求にしない。既存の出典検査、取消、遅着結果の破棄、音声と動作への反映防止を維持する。

確認ダイアログや設定項目は追加していない。依存関係、公開API、環境変数、保存形式、接続モデル、通常DB、人格、受入済みの口パク・PMX/VMDは変更していない。

## 検証と残る制約

修正前の範囲・合否条件と編集前コピーは `local/diagnostics/search-routing-20260924/` に保存した。

- 自動テスト：最終コードで検索サービス84件、現在情報11件、モデル切替の隔離統合11件、新しい検索操作と取消のUI9件、合計115件成功（プロセス分割で確認）。初回の対象120件成功後、レビューで見つかった「今日はいい天気」の誤検索と複数日時の曖昧な補完も修正した。初回件数を最終版全件の成功証明にはしない。
- Codex環境の統合確認：隔離したDB・QSettingsで実際のChatWindow・ApplicationBackend・Providerを使用。Luna 5.6／6の設定それぞれで、通常会話→ニュースまたは天気の検索→出典表示→画像の会話を検査した。HTTP応答はモックであり、外部への実通信はしていない。模擬回答の自然さはモデルの評価に数えない。
- 全体の `test.bat`：検索UIのエラー復帰テスト付近で進行が止まり、今回のpytestのPID・親子関係・起動コマンドを照合して終了。終了コード1で未合格。`test-bat.log` を保持。
- 診断：最終版の対象一括再実行で `Fatal Python error: Aborted` を記録。ログ捕捉を外した全件実行（`-s`、専用一時領域、faulthandler）も画像UIのエラー復帰中に異常終了し、終了コード3。検索UI単独でも異常終了し、追加でアクセス違反を記録した。原因は未特定。通常の雨衣アプリは終了していない。
- 異常終了後、影響箇所を分割した検査で上記115件を確認した。UI9件は対象を限定した検査であり、検索UI全21件の合格とは扱わない。テストの削除・無効化・判定緩和はしていない。異常終了したUI診断は後片付けのWindows終了APIが終了コード0を返したが、ログのFatal記録に基づき失敗と記録している。
- Ruff全体：`check .` 成功、`format --check .` は269ファイル成功。全体pytestの異常終了をRuffの成功で置き換えない。
- 未確認：Luna 6での実際のWeb検索・画像API応答、今回の修正後の利用者実機での検索成功。通常会話が動くという利用者報告を、検索APIの成功へ拡張しない。今回、新たな有料API要求は送っていない。
- 地名や日本語のすべての言い回しを認識する汎用的な意図判定ではない。対象を省略した検索の補完は直前の天気質問だけが対象。複数の日時・地域から一つを推測して選ばない。出典URLのない天気結果は引き続き採用せず、検索成功として扱わない。

## 利用者の次の操作

目的は、これまで通常会話へ流れていた天気の質問が、実際の検索に進むことの確認。Codexが済ませた自動テストをやり直す必要はない。次の送信は通常の有料API利用になる。

1. 雨衣のアプリを閉じ、いつもの `run.bat` で起動する。既存のLuna 6設定を使う。検索をオフにしている場合だけ、右上の歯車→「会話・音声」→「Web検索を許可」をオンにする。
2. 入力欄に「明日の千代田区の天気は？」と入力し、右側の三角矢印「送信」を押す。確認ダイアログや同じ地域の再入力は不要。
3. 検索中の表示の後、返答の近くに出典リンクが出れば取得成功。「検索できない」という普通の会話だけが返る場合は今回の修正の確認失敗。APIエラーや出典を確認できない旨が出る場合は、呼出し後の別の問題として区別する。
4. 中断する場合は実行中の「検索・返答を取消」、読み上げ中なら「音声・動作を停止」。処理が終わってから「少し雑談しよう」と送れば通常会話へ戻れる。
5. エラーが出たら追加送信を繰り返さず、その文面を知らせる。APIキーや会話全文は不要。検索だけを止めたい場合は設定の「Web検索を許可」をオフにでき、再起動後も保持される。

この修正だけでフェーズ10全体を受入完了にはしない。

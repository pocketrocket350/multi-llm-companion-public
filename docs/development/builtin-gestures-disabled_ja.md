# 組み込みの手振り・うなずきを不使用へ変更

2026-09-24。利用者がレビュー動画の01「右腕の手振り」と02「組み込みのうなずき」をともに「使用しない」と指定したため、雨衣PMXの通常会話で選択されないようにした。

## 変更内容

`GestureSelector` が暗黙に追加していた `builtin_wave` / `builtin_nod` と、登録VMDが使えない場合の組み込みへの代用を廃止した。登録済み候補だけを選ぶ。候補のない手振りは動作なしになり、nodには引き続き登録済みのオトカム氏YESを使用する。抑制ポリシーを無効にしても組み込み動作は復活しない。

オトカム氏の26件、YES／NO、標準待機の両手後ろ、回数制限、視線、まばたき、表情、音声設定は変更していない。設定項目・形式、DB、公開API、依存関係の追加はない。

今回の対象は雨衣PMXの通常会話選択。低レベルの描画分岐や2D表示部品を削除する変更ではない。採否確認用の古い動画は変更前の記録として残す。

## 実行した確認

- 自動テスト：変更後の選択器・PMX制御器の47件成功。未登録wave/nod/別名、抑制ポリシーのオン・オフ、リセット後、音声要件、登録nod、クールダウン、表情と視線の維持を確認。
- 全体：`test.bat` を1回実行し、1219件成功（160.15秒）、`ruff check .` 成功、全263ファイルの書式確認成功。全体の収集開始後に追加したPMX制御器のnod・small_nodの2ケースは、上記47件で別途確認した。変更した製品コードは全体実行前に確定している。
- Codex環境の統合確認：空の隔離DB・設定、現行雨衣PMX・既存描画で、waveから会話動作が始まらないこと、nodが `sample_otokam_030`、NOが `sample_otokam_029` を選び、再生後に標準待機へ戻ることを確認。描画・布エラーなし。
- 通常DB・設定・QSettings・PMX・VMDは前後のハッシュ一致。新規の外部API要求0、音声出力なし。
- 利用者実機：再起動後の日常会話での反映は未確認。今回の全体検査の成功を、以前の別タスクのQt異常終了の原因解消と同一視しない。

証拠は `local/diagnostics/disable-builtins-20260924/` の `test-bat.log`、`test-bat-exit.txt`、`integration-result.json`、`isolated-app/*-during.png`・`*-returned.png`。前提・合否条件は `plan.md`、差分は `changes.diff`。

## 利用者の次の操作

1. 起動中のアプリを閉じ、いつもの `run.bat` で起動し直す。追加設定は不要。
2. そのまま会話を続ける。自己紹介などで以前見えた組み込みの右腕動作は選ばれなくなる。オトカム氏のYESなど、採用済みの別動作は継続する。
3. 同じ右腕の姿勢が再び出た場合は「音声・動作を停止」を押し、直前の入力と画面を知らせる。停止後は通常の入力から会話を再開できる。

選択器・描画の検査を利用者へやり直し依頼するものではない。採否指定は反映済みで、アプリ全体やフェーズ全体の新たな受入完了とはしない。

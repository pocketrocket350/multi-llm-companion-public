# 背景と雨衣の表示倍率を連動

作成日: 2026-09-24。実装・対象自動テスト・Codex環境の隔離統合確認済み。全体検査は失敗・未解消。利用者の見た目の受入は待ち。

同日追記: 利用者が背景と雨衣の拡大・縮小の連動を確認した。床がないことへの追加依頼を受け、[床付きの提供画像へ差し替え](floor-background_ja.md)た。以下の原本・検査結果・床がないという記述は、差し替え前の記録。

## 変更と根拠

従来は背景を表示欄の幅・高さから独立に切り抜き、人物だけをカメラで拡大していた。このため全身からバストアップにしても背景の額や本棚が同じ大きさのままだった。

通常の全身・バストアップ表示では、背景も人物と同じカメラの倍率と注視点で切り取る。原本に対する身長と足元の位置を固定し、本棚の右側に立つ構図とした。ホイール、表示範囲の切替、ウィンドウのサイズ変更で、人物と背景の大きさの関係を保つ。

背景の縦横比は維持する。全身や縮小表示で原本の外側が見える場合は、既存の淡い背景色で埋める。人物の向きを変えるドラッグ、呼吸、表情、会話動作では部屋を回転・振動させない。これは提供された平面イラストの表示調整で、部屋の3D化や床・影の描き足しではない。

既存のモデル・モーション・姿勢・表情・バストアップ既定は維持した。GPU未使用時の簡易描画にも、既存の人物倍率に応じた背景表示を接続した。簡易描画自体の画角・姿勢品質をGPU描画と同等に作り直す変更は含めない。通常設定からは選べない明示VMD演出とモデル未読込時は従来の背景表示を保つ。

追加依存、公開API、環境変数、設定・保存形式の変更はない。通常DB、人格、設定、QSettings、背景原本、PMX/VMDを変更しない。有料API要求は0件。

## 利用者が次に行う操作

目的は、ご自身の画面で「同じ部屋の中に雨衣がいる」と感じられる構図になったか判断すること。数値・自動検査を重ねて行う必要はない。

1. 起動中のアプリを閉じ、いつもの `run.bat` で起動する。会話・検索や音声の実行は不要。
2. 雨衣の上でマウスホイールを1～2目盛り動かす。雨衣と背景の水玉・額が一緒に拡大・縮小するのが正常。
3. 右上の「設定」→「表示・アバター」で「雨衣の表示範囲」の「全身」と「バストアップ」を切り替える。背景の同じ場所に立ったまま、見る範囲が変わるのが正常。全身表示では縦長の原本の左右に余白が出る場合がある。
4. 好みの表示範囲へ戻して設定を閉じる。拡大率と向きを戻す場合は同じタブの「雨衣を正面に戻す」を押す。

背景だけが固定倍率のまま、画像の縦横比が崩れる、以前になかった描画の欠けが出る場合は不合格。操作を止め、「雨衣を正面に戻す」かアプリの再起動で復帰する。残る場合は、その画面と全身／バストアップのどちらかを知らせる。

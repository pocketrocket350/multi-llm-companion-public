## 編集前の計画と合否条件

- 左に現行雨衣PMX、右に会話。標準バストアップ。提供背景原本をlocalから表示し、配布資産へ複製しない。背景がない環境は淡い水色にする。カメラの表示範囲だけを変え、モデル・姿勢・VMD・表情・視線・物理・音声種類を変えない。
- 水色の画面、送信は水色・マイクはミント、操作文字は濃紺。利用者は右寄せの緑、雨衣は左寄せの白い吹き出し。引用・画像解析範囲は返答近く、文字とリンクを保持する。
- 履歴は入口から必要時に開閉。設定に既存の記憶・能動会話・接続音声・アバター調整・診断をまとめる。表示モード・最前面・状態表示は既存QSettingsキーだけを利用する。
- 入力近くに生成・録音・外部送信・音声中の状態と停止を表示し、待機中は隠す。重大なエラーは診断の開閉に影響されない。停止の世代破棄・音声・口形・表情・視線・動作・保留処理の範囲を維持。
- 画像許可の追加ダイアログは出さず、画像選択と送信による許可を保持。Webの確認・許可は今回の廃止対象ではない。
- 小画面800×600および代表DPI、履歴・設定、長文・リンク、処理中・停止・エラー、キーボード操作を隔離アプリで検査する。生成画像のモックを実装済みの証拠にはしない。
- UI・PMXの対象回帰とRuffを実施し、最後にtest.bat。描画性能は同じPMX・静止カメラ・短い計測条件で確認し、モデルの再読込や背景の毎フレーム再読込を追加しない。
- 利用者の採用済みデザインと、変更後の実機受入は区別する。自動・Mock実アプリ・実API・実音声の証拠を分ける。新規依存・設定形式・DB形式は追加しない。

## 実装した内容

- PySide6の既存ウィンドウを左PMX／右会話へ配置。履歴を折りたたみ、既存の設定・記憶・能動会話・表情・視線・モーション管理を3タブの「設定と詳細」へ移した。標準Qtだけを使い、新規依存・環境変数・YAML・DB項目を追加していない。
- 吹き出しはQtの選択可能な本文とリンクを維持する小さなウィジェット。利用者は緑、雨衣は白。応答途中は既存の行を再利用し、終了後も出典と画像情報を返答近くに表示する。
- 待機中は活動欄を隠し、録音・生成・検索・画像解析・音声中だけ状態と停止を入力近くに表示。エラーはメイン画面で表示する。通常生成中の停止も世代を無効にし、遅着の表示・保存・音声化を防ぐ。
- 画像の追加許可ダイアログは廃止済みの操作を維持。選択だけでは通信せず、送信で有効にする。Webの送信確認は維持。
- 提供背景をプロセスで一度読み、GLコンテキストごとに一度転送。元画像の縦横比を保って中央で切り取り、SSAAと通常描画の両方でモデルの背面に描く。背景なしは淡い水色。CPU簡易表示も同じ原本を使う。
- 標準バストアップの画角を採用案に合わせ、小画面で履歴を開くときは頭が横に切れないよう倍率を抑える。全身／バストアップを設定から選択できる。同日の[設定整理](settings-ux-refinement_ja.md)で、VMDカメラの開発用選択は通常UIから撤去した。PMX・VMD・物理・姿勢・表情・視線・音声設定を変更していない。
- QSettingsは従来の4キーだけ。診断の表示選択は設定内に移った診断欄に適用し、保存と復元を確認した。入力欄はEnter送信、Shift+Enter改行、Tabで送信ボタンへ移動する。

### 途中の失敗・未解消

- 最初の対象検査は4件失敗。表示場所・文言変更の未更新テスト2件と、削除済みConversationViewへの非所有タイマー呼出し、その後の残留状態が原因だった。表示変更の検査を等価な診断画面・文言へ更新し、スクロールタイマーをビュー所有にして修正。最終全体検査では成功。
- 最初の実画面では本文が欠けた。継承された余白と文書高さの不一致を修正し、短文・長文の実スクリーンショットとviewport高さのテストで再確認。行の不要な上下余白も修正。
- キーボード確認でTab移動を追加し、最前面変更直後に未アクティブだった試験側のイベント処理を修正。QSettingsの復元サイズ検査は、offscreen画面の幅内に収まる780×600で元サイズの復元を確認した。
- `interaction-01` は再生fixtureに検索上限メタデータが欠け、アプリが未完了検索として正しく拒否した。実APIエラーではない。fixtureを完了済み出力だけにし、`interaction-02` で成功。製品の検索完了条件は緩めていない。
- 中間の対象検査と最初の `test.bat` がUI検査途中で進まなくなり、中断した（`final-target.log`、`test-bat.log`）。その実行を成功扱いにしていない。停止時診断を有効にした最終全体実行は成功したが、最初の停止原因は未特定。以前のQt Abort記録も解消と断定しない。
- 拡大時の前髪のシアン色の線は、背景offと編集前の `DensePmxWidget` を使った隔離比較 `baseline/normal.png` でも再現。今回の背景追加による回帰ではない。髪材質・PMXを変えず未解消として残す。
- 新11の利用者実機受入、実マイク録音の再評価、全DPI・全画面サイズ、長時間性能は未実施。フェーズ8・9の受入済み全項目をやり直すものではない。新12の60分会話・実時間8時間待機は開始していない。

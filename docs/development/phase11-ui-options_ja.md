## 目的と共通方針

雨衣と会話する画面を、開発用の状態一覧から切り離す。会話とアバターの配置・比率が異なる3案を比較し、利用者の指定を反映したB修正版を採用した。

- 通常は雨衣、会話、入力、送信、マイク、履歴・設定の入口だけを表示する。
- モデル名、トークン数、表情・視線・動作名、GPU・物理情報などは設定内の詳細・診断へ移す。
- 録音・生成・検索・再生などの実行中は、その状態と停止を入力の近くに表示する。安全上必要な録音・カメラ・外部送信表示は隠さない。
- 会話履歴は必要なときだけ開く。記憶・能動会話・アバター調整などは既存の管理画面を再利用する。
- 本体はPython/PySide6のまま。Web化、依存追加、保存形式の変更は今回の案作成に含めない。

画像はAI生成の選択用コンセプトであり、Qtで動く画面のスクリーンショットではない。灰色の人物は配置を示す仮の人物で、雨衣の見た目を作り直す案ではない。実際の雨衣PMX、VMD、表情、音声、利用者の会話・記憶は画像生成へ送っていない。画像内の会話は作成した短い例文。

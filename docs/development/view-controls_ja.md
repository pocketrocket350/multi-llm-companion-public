# 表示操作・会話日時の改善

**現行操作（2026-09-28確認）**：標準は正面から左右180度。設定の「モデルを横方向へ続けて回転できるようにする」で何周でも回せる。全身表示は高さに全身が収まる標準倍率より縮小しない。[9月25日の訂正](dialogue-view-fix_ja.md)と[現行の操作案内](phase11-user-check_ja.md)を優先する。以下の左右90度・横360度という説明は訂正前の履歴であり、現在の操作仕様ではない。

2026-09-25。今回の依頼に基づく実装範囲と検証記録。

## 実装前の範囲・合否条件

- マウスのモデル回転は横方向のみ。既定は正面から左右90度の計180度。設定の「モデルを横360度回転できるようにする」で一周でき、オフに戻すと既定範囲へ収める。
- 全身／バストアップの切替は設定の選択欄を撤去し、モデル表示部の隅のアイコンへ移す。モーション・表情・姿勢は変更しない。
- 履歴／モデル／会話の境界をドラッグでき、幅と回転設定を既存のQSettingsへ保存して次回起動時も復元する。履歴の開閉・小画面・従来設定からの起動を維持する。
- 本文とは別に各発言の時刻と日付区切りを表示する。履歴は既存DBの作成日時をPCのタイムゾーンへ変換する。時刻がないデータに架空の日時は付けない。生成途中で時刻が変わらないようにする。
- 新しい依存・外部API・DBスキーマ・YAML形式は追加しない。既存設定の削除や通常データへの検査会話の追加は行わない。

今回の依頼は、上記操作と設定の記憶を含む。既存QSettingsへの当該キー追加と、保存済みの日時をUIへ渡す任意フィールドをこの範囲で扱い、追加承認は求めない。

変更前を `local/diagnostics/view-controls-20260925/before/` に保存した。変更箇所の回帰とRuff、全体 `test.bat`、DB・QSettingsを分離した実アプリでのドラッグ・切替・回転・日時・再起動を確認する。

## 実装した内容

- 通常のマウスドラッグは正面を中心に左右90度まで。上下方向のドラッグでは傾けない。設定の「表示」にある「モデルを横360度回転できるようにする」で背面まで回転できる。設定は再起動後も維持する。背景・待機モーション・表情・視線・口パクは変更していない。
- モデル右上の人物アイコンで全身／バストアップを交互に切り替える。アイコンとツールチップは次に切り替わる表示を示す。設定の表示範囲選択欄は撤去した。
- 履歴／モデル／会話の間を8pxのドラッグ可能な境界へ変更。従来の表示幅選択欄はこの操作へ置き換えた。幅は既存QSettingsの `layout/main_splitter` と `layout/content_splitter`、回転許可は `camera/rotation_360` へ保存する。全身／バストアップは既存 `camera_view` を使用する。旧 `companion_view` は削除せず、新しい幅の記録がない場合の初期値に使う。
- 吹き出しの外側に `HH:mm`、各日の先頭に `YYYY/MM/DD（曜日）` を表示する。DBに保存済みのUTC日時をPCのタイムゾーンへ変換する。音声本文と出典は別の経路のまま維持する。

- 生成中の新規返答は表示開始の時刻、保存済み履歴はDB確定時刻を使用する。生成が分・日付境界をまたぐと、履歴を開き直した時に確定時刻へ変わる場合がある。日時は本文や読み上げへ含めない。

## 利用者の操作

新しい操作位置と幅が好みに合うかを見るための案内。再起動の保存検査や自動テストを利用者に重ねて依頼するものではない。

1. 雨衣アプリを閉じ、いつもの `run.bat` で起動する。通常の会話と設定をそのまま使える。
2. モデル表示部の**右上の人物アイコン**を押す。全身とバストアップが切り替わる。マウスを重ねると「全身表示に切り替える」または「バストアップに切り替える」と出る。
3. 雨衣の上を左右へドラッグする。標準では横顔の位置で止まり、上下ドラッグでは傾かない。背面まで見たい場合は、右上の歯車→「表示」→「モデルを横360度回転できるようにする」にチェックする。戻すときはチェックを外す。「雨衣を正面に戻す」で正面へ戻せる。
4. 左上の三本線で履歴を開く。履歴とモデルの間、モデルと会話の間の水色の境界を左右へドラッグする。変更した幅が次回にも使われる。履歴が不要なときは三本線で閉じる。
5. 会話の吹き出し脇に時刻、日が変わる位置に日付が表示される。出典リンクや本文の選択は従来どおり使える。

正常な状態は、アイコンが隠れず、入力欄を操作でき、境界の移動と回転が意図した範囲で止まること。読みにくい場合は幅を戻すか履歴を閉じ、向きは「雨衣を正面に戻す」で戻す。画面が切れる・操作が止まる場合はその操作を止め、画面サイズと直前の操作を添えて知らせてください。読み上げ中の停止は従来の「音声・動作を停止」を使用する。

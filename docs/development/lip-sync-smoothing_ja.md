# アップ表示での口パク改善

2026-09-24。利用者の「動きが急で、パクパクしすぎる」に対する修正記録。

同日、利用者から「見た目の自然さ はよくなりました」と確認されたため、今回の口パクの自然さの調整は利用者受入済みとする。音素推定の精度や高負荷時の性能まで受入範囲を広げない。

## 変更内容

今までは「あ・い・う・え・お」の口モーフを強度1.0で即座に切り替え、閉口も即座に0にしていた。発話中は口形の重みを時間で補間する。母音の切替は時定数50 ms、短い閉口は60 msで減衰し、母音どうしを重ねても全開2個分にはしない。停止・割り込みは補間せず直ちに閉口する。

音声の実再生位置、音素／文字推定の時刻表は変更していない。口だけの変形を既存の33 ms描画タイマーで更新する。身体の動作をオフにしても発話中の口だけを更新し、両方停止ならタイマーも止める。手動の口モーフ確認は従来どおり即時表示する。

口差分をGPUへ渡す既存経路を再利用した。姿勢キャッシュの口形位置がずれていた点も修正し、口更新だけでモデル全体を再計算しないことを検査した。遅れて完成した姿勢にも「今の口の重み」を使う。

表情に含まれる口モーフと発話口形を加算する従来仕様は維持した。表情・視線・まばたき・身体モーション、PMX/VMD原本、音声設定、依存・公開API・保存形式は変更していない。

既存実装との比較として [Rhubarb Lip Syncの口形説明](https://github.com/DanielSWolf/rhubarb-lip-sync#mouth-shapes) を確認した。同資料には口形間の中間形が示されているが、今回のコードは移植せず、既存のPMXモーフ加算を使った。

## 検証結果と範囲

事前条件は `local/diagnostics/lip-smoothing-20260924/plan.md`。資料・コード確認だけでなく、同じローカル合成WAV（5.095秒）を変更前後で使用した。

| 自動テスト済み | 最終対象199件成功。新規10件には開口時間、短い／長い無音、停止後、描画周期の違い、GPUと簡易描画、表情・まばたき、遅着姿勢、全体再構築防止を含む |

最初の対象検査は157件成功・新テスト1件失敗だった。簡易描画の固定ピッチ0.1を期待値が考慮していなかったため、座標変換を含む期待値へ修正した。実装の失敗を無効化していない。追加の遅着姿勢テストを含め、最終対象199件が成功した。

固定30fpsで同じ音声位置を再現した比較では、1フレームの口形重みの最大変化が **1.000 → 0.487**。合計重みは常に1.0以下。90%の開口は150 ms以内、長い無音の閉口は300 ms以内、停止は補間を待たず0になる。固定時刻の映像は実時間性能の証明とは分けている。

実時間計測（同じWAV・実PMX・640×760・バストアップ・標準描画、録画なし）は次のとおり。短い一回ずつの計測であり、全場面の速度保証ではない。

| 指標 | 変更前 | 最終版 |
| --- | ---: | ---: |
| 口メッシュ更新 中央値 | 8.12 ms | 8.53 ms |
| 同 p95 / 最大 | 16.34 / 16.57 ms | 17.11 / 18.72 ms |
| 軽量タイマー間隔 中央値 | 33.42 ms | 33.86 ms |
| 同 p95 / 最大 | 55.53 / 89.42 ms | 63.31 / 100.29 ms |

口処理自体は33 msを超えなかった。UIタイマーには前後とも周期超過が残り、安定30fpsの合格とは扱わない。中間案の独立タイマーでは中央値42.03 msの計測もあり、プロファイル確認後に既存タイマーへ統合した。過負荷でフレームが空いた場合は、古い形を順番に再生せず現在時刻へ追従するため、通常時より大きく形が変わる可能性は残る。全体の長時間・性能受入はフェーズ12のまま。

ローカル合成の応答には音素時刻がなく、設定名TanakaSanに対して接続先が返した実ボイスはui_ja_JPだった。この検査をTanakaSanの実音声検証とは扱わない。今回、ボイス設定は変更していない。外部LLM/APIの有料要求は0回。試験DB・設定・QSettingsを隔離し、通常DB・ローカルYAML・通常QSettingsの前後一致を確認した。

## 利用者に案内した確認操作（実施・受入済み）

以下は受入前に案内した手順の記録。今回の利用者確認をもって終了し、同じ確認を再依頼しない。

1. アプリを閉じ、プロジェクトの `run.bat` をダブルクリックして再起動する。VoiSonaは普段どおりの状態でよい。
2. いつも違和感があったアップ表示で「今日の気分を、二、三文で教えて」と入力して送信する。
3. 口が一瞬で全開・全閉になる感じが弱まり、音声から大きく遅れて見えなければ今回の調整は良好。まだパクパク感が強い、または口が遅れて見える場合は、その場面・返答文を知らせる。
4. 途中で止めたい場合は会話欄の「音声・動作を停止」を押す。次の入力から普通に会話へ戻れる。

この見た目の受入を、フェーズ10全体やフェーズ12の性能受入へ自動的に拡張しない。

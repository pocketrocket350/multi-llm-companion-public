2. 右下の入力欄へ **「今日の世界のニュースを一つ調べて、一緒に話そう」** と入力し、**「送信」** を押します。通常のAPI料金が発生します。画像添付は不要です。

成功の目安は、出典を見ながら自然に話せ、ニュースの選び方と説明の長さが希望に合うことです。出典のない断定や停止後の古い音声の再開があれば、その場で停止し、再送せず知らせてください。結果は **「ニュースの選び方はよい／気になる媒体がある」「返答の長さ・話しやすさ」** の短い感想で十分です。操作上の問題があれば操作番号も添えてください。

天気はURL出典が返らず不採用になる場合があるため、今回の必須入力にはしていません。既知のQt検査の停止原因、前髪の表示制約は継続記録に残しており、利用者に原因調査を依頼するものではありません。フェーズ10全体を自動的に受入完了とはしません。

## 画像について話す

1. 会話欄の下の **「画像を添付」** を押します。外部へ送ってよいPNG/JPEG/WebPを1枚選びます。動画・PDF・Word等は対象外です。15MB・2400万画素を超える画像や壊れたファイルは理由を表示して止まります。カメラは使いません。
2. 入力欄の近くに画像のプレビューとファイル名・送信サイズが出ます。これは長辺1536px以下へ縮小し、位置情報などの付加情報を除いた送信画像です。選択だけでは通信しません。取りやめるなら **「画像を外す」** を押します。
3. **「この画像には何が見える？ 気になったところを短く教えて」** と入力し、**「送信」** を押します。画像の追加確認ダイアログは出ません。プレビューと質問を確認して送信する操作が、選択した画像を送る明示許可になります。送信先・送信内容・費用は画像の横に表示し、その説明へマウスを重ねると料金や保存範囲の補足を読めます。選択だけでは送信されません。
4. 処理中は **「画像解析・返答のためOpenAIへ送信中」** と **「画像・返答を取消」** が出ます。完了すると画像に沿った短い返答が表示・読み上げされ、返答の近くに画像名・解析範囲が残ります。原本・画像データ・パスは履歴に残らず、本人の恒久的な事実として自動記憶しません。
5. 画像に沿って話せるか、説明の長さ・声・親しさが好みに合うかを判断してください。細かい文字などが読めない場合に断定せず、分からないと伝えるのも正常です。画像原本をもう一度見せる場合は再添付が必要です。

1回の画像会話は解析1要求＋返答1要求です。通常入力料金は100万トークン0.20米ドル、出力1.20米ドル。画像も入力として課金され、画像入力部分はおよそ0.001米ドル以内が目安ですが、質問・解析出力・通常会話の料金は別です。画像を付けたターンではWeb検索しません。

## ニュースについて話す（任意）

追加承認2要求による日本語検索語・日本語報道の探索、NASA出典と日本語返答の実API確認は完了しました。日本語記事の選定を毎回保証するものではありません。画像だけの体験確認で終了して構いません。検索も試す場合、対象は日本国内に限定せず、世界の幅広い話題とし、日本語で読める身近な報道を優先します。媒体や国を明示した依頼が優先され、馴染みの薄い媒体を必ず排除する仕組みではありません。

1. 会話欄の下へ **「今日のニュースを一つ調べて、一緒に話そう」** と入力して「送信」を押します。
2. 「Web検索の送信内容」が開きます。検索文を読み、個人情報が不要なら短く編集できます。**「Web検索を許可する（この起動中だけ）」** をチェックし、**「詳しく説明する」** はオフのまま、**「この内容で検索」** を押します。検索側へ送られるのはこの文と現在日時です。返答生成には、通常の人格とこの隔離会話も使います。
3. 実行中だけ入力欄の近くに送信中表示と **「検索・返答を取消」** が出ます。完了後、短い返答の近くに **[S1]等の出典リンク・タイトル・取得日時・公開日時** が出ます。公開日時が「不明」でも、取得日時から公開日を捏造しないための正常表示です。出典を押すと通常のブラウザーで開きます。
4. 現在のTanaka Sanで短く説明されること、雨衣の表情が崩れず会話できることを確認します。**聞きやすい長さか、話したくなる返答か**を判断してください。Codexでは実再生・口形タイムライン・停止を確認しましたが、音色や自然さの主観的な合格は付けていません。
5. 続けて **「どんなところが気になった？」** と送ります。追加検索なしで普通に話せるかを確認します。最初から詳説を望む場合は、手順1の検索を **「今日の世界の科学ニュースを一つ調べて、詳しく説明して」** に置き換えて、確認画面の「詳しく説明する」をオンにします。この隔離起動では検索は1回までです。

短答/詳説の切替は、この確認画面で選びます。現在の天気検索は、サービスがURL出典を返さず不採用になる場合があるため、今回の体験確認の必須入力にはしません。

## 「Web検索の送信内容」が出る理由

このダイアログはAPIの技術的な必須条件ではありません。今回の検索文を見て編集し、秘密や不要な情報を送らないこと、費用が発生する外部検索を自分で実行すること、天気の地域・短答/詳説を選ぶことのために追加しました。以前の方式選択で「送信前に検索文を確認する」方針が採用されています。毎回の別ダイアログ以外でもこれらを実現できますが、今回の理由の質問を廃止指示とは扱わず、現在は維持しています。

## 停止と復帰

- 検索中なら **「検索・返答を取消」** を押します。新しく文字を入力する、マイクを開始する、会話メニューでWeb検索を無効にする操作でも、保留中の検索結果を破棄します。
- 画像解析中なら **「画像・返答を取消」** を押します。新しい入力・マイク開始・画像許可の無効化でも遅着を破棄します。画像をまた送るには選び直してください。
- 読み上げ中なら、新画面の右側、会話入力欄の上に実行中だけ出る **「音声・動作を停止」** を押します。音声と動作が止まり、古い発話が後から再開しなければ正常です。既に確定した返答と出典は履歴に残ります。
- 「取消済み（通信の終了待ち）」が消えたら **「お茶を飲んでひと息つこう」** と送信します。検索なしで会話へ戻れれば正常です。送信済みの通信や料金自体は取り消せません。
- Web検索をオフにするには、入力欄の下の **「会話メニュー」→「Web検索を許可（この起動中）」** のチェックを外します。アプリを閉じても許可は失われ、次回はオフです。
- 画像送信をオフにするには **「会話メニュー」→「画像の送信を許可（この起動中）」** のチェックを外します。選択中の画像も外れます。次回起動時にはオフですが、新たに画像を選び「送信」を押すとその操作で有効になります。どちらの操作にも追加の確認ダイアログは出ません。

画像1会話2要求＋検索1会話2要求＋追いかけの会話1要求＋復帰の会話1要求で合計6要求です。上限やAPIエラーが出たらそこで終了し、再起動による追加試験を続けないでください。

## 合否と知らせてほしいこと

返答が親しみやすく、短答/詳説が使い分けられ、出典を見ながら会話でき、停止後に古い声が再開しなければ、体験面の受入候補です。これを確認する前にフェーズ10を自動的に受入完了にしません。

「出典なしなのに調べたと言う」「知らない内容を記憶したと言う」「停止後に声が再開する」「音声が出ない」場合は、停止してそれ以上の有料確認を行わないでください。
報告は **操作番号・短い実返答・気になった点・文字か音声か** で十分です。キーや通常の会話全文は不要です。
出典なし・拒否・タイムアウトが明示され、内容が表示されず通常会話へ戻れる場合は、失敗を安全に扱う動作です。検索成功・体験受入とは別に扱います。

終了は処理完了後に右上の「×」。通常の `run.bat` で、今までの会話・設定に戻れます。検証データを削除する必要はありません。
最新の採用範囲は10-1と選んだ静止画像1枚（10-2）です。動画・文書・カメラと個別外部連携（10-3）は未採用です。画像と検索の許可は別々です。

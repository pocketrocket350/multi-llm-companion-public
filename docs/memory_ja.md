# 長期記憶

会話から今後も役立つ情報を保存し、関連する会話で使います。既定では記憶候補を自動承認します。

会話中に記憶が保存されると、会話欄の右上に「記憶を1件保存しました。」と小さく表示します。自動承認がオフなら「記憶の候補が1件あります（確認待ち）。」と表示します。本文は通知へ載せず、会話や読み上げにも加えません。

通知は初期設定では約6秒後にゆっくり消えます。**設定 → 表示 → フローティング通知** で、**記憶の通知を表示** のオン・オフと表示時間（1～30秒）を変更できます。通常の案内とは別々に保存されます。通知を非表示にしても記憶の保存・候補の作成は続きます。

マウスを重ねている間は通知が残り、「×」ですぐ閉じられます。「記憶を管理」を押すと設定を経由せず確認できます（返答の処理中は押せません）。見逃した場合も、下の手順で後から確認できます。会話を切り替えるか次の送信を始めると、前の通知は消えます。通知が消えても記憶は削除されません。

## 確認・編集する

1. **設定 → 会話 → 記憶を管理** を開きます。
2. 一覧から記憶を選び、本文・分類・根拠の会話を確認します。
3. 修正したら **修正を保存**、不要なら **選んだ記憶を削除** を押します。

保存前に確認したい場合は **候補を自動承認する** をオフにします。確認待ちの候補は **選択した候補を承認** を押すまで会話で使いません。残さない候補は **選んだ記憶を削除** を押します。

## 利用を止める・削除する

**今後の会話で保存した記憶を使う** をオフにすると、保存済み記憶の利用を止められます。データは残ります。削除するときは個別削除または **すべての記憶を削除** を使います。削除は元に戻せません。

「覚えないで」「記憶しないで」と書いた発言は記憶候補にしません。「忘れて」は対象が一意に分かる場合に削除します。対象が曖昧なら管理画面で選んでください。

## 保存先と送信

記憶は会話と同じDBへ保存されますが、履歴を削除しても記憶は別に残ります。外部LLM使用時は、語句が関連する承認済み記憶を優先し、意味による参照・訂正のため、同じ話題や最近の承認済み記憶も補って送信します。会話の **使用した記憶** から参照内容を確認できます。

秘密や一時的な情報を保存対象から除く処理がありますが、自動判定は完全ではありません。秘密情報は入力せず、保存内容も必要に応じて確認してください。

詳細な参照件数・関連度・利用期限は [memory.example.yaml](../config/memory.example.yaml) を参考に `local/memory.yaml` で変更できます。利用期限を過ぎてもデータ自体は削除されません。保存・移行は [バックアップ](backup_and_recovery_ja.md) を参照してください。

`max_context_memories` は補完分も含めた最大件数です（既定5件）。`min_relevance_score` は語句検索で優先する候補の基準で、補完された記憶の送信は止めません。保存済み記憶の送信全体を止める場合は、**今後の会話で保存した記憶を使う** をオフにしてください。

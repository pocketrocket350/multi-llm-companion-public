# キャラクターの話し方を変える

人格設定は、名前・口調・性格と会話の進め方をまとめたものです。同梱の見本はオリジナルの会話案内役です。

## 画面で編集する

1. **設定 → 会話・音声 → 人格を編集** を開きます。
2. **話し方・性格** で名前・一人称・口調など、**会話の方針** で返答の長さ・質問頻度などを編集します。
3. **保存** します。次の返答から反映され、再起動後も残ります。変更を保存しない場合は **キャンセル** で閉じます。

人格設定も外部LLMへ送られます。APIキーや個人の秘密を書かないでください。MMDや音声を導入しても、公式の人格設定が自動で付くわけではありません。

## ファイルで編集する場合

アプリを終了し、`local/persona.yaml` を別名でコピーして控えを残します。編集するのは元の `local/persona.yaml` です。

| 項目 | 内容 |
| --- | --- |
| `character` | 名前・一人称・口調・性格 |
| `behavior_policy` | 返答の長さ・質問頻度・会話の方針 |
| `official_facts` / `interpretations` | 確定した設定と、それと区別する解釈 |
| `forbidden_inferences` / `anti_patterns` | 推測しない内容・避ける表現 |
| `dialogue_modes` | 聞き役・説明など、場面ごとの方針 |
| `system_prompt_appendix` | その他の追加指示 |

使える項目は [設定見本](../config/persona.example.yaml) を参照してください。内部の回答形式やモーション名を追加指示へ書く必要はありません。

旧形式の `name` と `system_prompt` も読み込めますが、新形式の項目と混在できません。設定エラーが出た場合は直前の編集を戻します。人格設定を配布する場合は [権利表記](rights_and_credits_ja.md) も確認してください。

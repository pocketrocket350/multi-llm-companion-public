# アバターと表情

初期状態はコードで描く2Dアバターです。雨衣MMDを使うには、PMXとテクスチャを用意し、[音声・MMDの設定](reference_setup_ja.md) を行います。

## 表示を調整する

MMD表示右上の人物アイコンで **全身／バストアップ** を切り替えられます。表示領域の境界をドラッグすると幅を調整できます。読込みやモーフの状態は **設定 → 診断情報** で確認します。

## 表情を確認・編集する

1. **設定 → 表示 → 表情を管理** を開きます。
2. 保存済みプリセットを選ぶと、自動でプレビューされます。
3. 調整するときは **編集** または **複製** を使います。目・眉・口などの変形を組み合わせ、強さを調整します。
4. **組合せを試す** で確認し、保存名と **会話で使う場面** を選んで保存します。保存するまでは会話用の設定は変わりません。
5. **プレビューを終了 → 閉じる** で通常表示へ戻ります。

モーフとはPMXに入っている表情などの変形です。「対応するモーフが不足」と出る場合は、モデルの版と設定の対応を確認してください。動作の切替は [モーションを管理](vmd_catalog_ja.md) を使います。

## 設定ファイルで調整する

編集対象は `local/app.yaml` の `avatar_config_path` が指すファイルです。通常は `local/avatar.yaml`、基準構成では `local/avatar.reference.yaml` です。終了してから対象を別名でコピーし、必要な項目だけ変更します。

| 項目 | 内容 |
| --- | --- |
| `three_d.enabled` | MMD表示の有効・無効 |
| `three_d.provider` | PMX表示は `pmx_preview` |
| `three_d.model_path` | `local/models/mmd` 内のPMXへのパス |
| `three_d.expression_presets` | 表情の組合せと強さ |
| `three_d.emotion_presets` / `emotion_preset_variants` | 感情と表情候補の対応 |
| `three_d.mmd_mapping` | PMXのモーフ・ボーン名との対応 |

設定見本は [基準構成](../config/avatar.reference.example.yaml) と [2D初期設定](../config/avatar.example.yaml) を参照してください。別のPMXを使う場合は、そのモデルのモーフ・ボーン名へ合わせる必要があります。

口パクは音声の実再生位置へ同期し、視線や動作と組み合わせて表示します。視線専用の管理画面はありません。

## 表示が崩れたとき

**音声・動作を停止**、プレビュー中は **プレビューを終了** または **プレビュー停止** で止めます。戻らなければ終了し、直前の設定変更を戻してください。MMDを使わず起動するには、選択中のアバター設定で `three_d.enabled: false` にして再起動します。[既知の制限](v1_candidate_ja.md) と [復旧手順](backup_and_recovery_ja.md) も参照してください。

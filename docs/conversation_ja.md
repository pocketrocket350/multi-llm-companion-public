# 会話の操作

## 送信・履歴・終了

入力欄に文章を書き、Enterまたは **送信** で送ります。Shift+Enterで改行できます。日本語変換中のEnterは変換確定に使います。

左上の三本バー **履歴** から以前の会話を再開できます。別の話題は **新しい会話** で始めます。削除するときは対象を選んで **この履歴を削除** を押します。削除は元に戻せません。終了は処理が終わってから右上の **×** を押します。

## マイクと読み上げ

設定後、入力欄右の **マイク** で録音を開始します。認識文を確認してから送信します。録音を取り消すには **録音停止**、読み上げと動作を止めるには **音声・動作を停止** を押します。準備方法は [音声ガイド](audio_ja.md) にあります。

## Web検索

1. **設定 → 会話・音声 → Web検索を許可** をオンにします。
2. 調べたいことを書いて送信します。
3. 検索結果を使った回答には出典リンクが表示されます。中止は **検索・返答を取消** です。

## 画像について話す

1. **設定 → 会話・音声 → 画像の送信を許可** をオンにします。
2. **画像を添付** でPNG・JPEG・WebPを1枚選び、質問を書きます。選択しただけでは送信しません。
3. **送信** で画像と質問を送ります。送信前は **画像を外す**、送信中は **画像・返答を取消** で取り消せます。

続く質問には既出の説明文を使います。画像の新しい細部を尋ねるときは再添付してください。

検索と画像はOpenAI公式API接続で、対応するモデルを使う場合に利用できます。許可の変更はすぐ保存されます。送信済みの通信や発生した料金は取消操作でも戻りません。

## 能動的な話しかけ

1. **設定 → 会話・音声 → 能動的な話しかけ** を開きます。
2. **能動的な話しかけを有効にする** をオンにします。読み上げる場合は **能動発話を読み上げる（現在の音声設定を使用）** もオンにします。
3. 待機時間・最短間隔・静かな時間帯を設定して **保存** します。すぐには話し始めない場合があります。

停止するときは同じ画面で有効チェックを外して保存します。実行中の音声は **音声・動作を停止** で止められます。外部LLMを使う場合は、開いている会話や人格設定などを送信し、料金が発生することがあります。

## 設定と診断

右上の歯車 **設定** から接続先・マイク・記憶・表示を変更できます。**診断情報** には使用中のモデル、各機能の状態、APIが返したトークン使用量が表示されます。トークン数は請求額ではありません。

会話や記憶などが外部LLMへ送られるため、秘密情報は入力しないでください。記憶の確認・削除は [記憶を管理](memory_ja.md)、接続の問題は [復旧手順](backup_and_recovery_ja.md#起動や接続で困ったとき) を参照してください。

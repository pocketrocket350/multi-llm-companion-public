# VMDカタログの使い方

**オトカム氏のVMD 26件を、出典・原文Readme付きで同梱しています。** 初回の `setup_windows.bat` で配置されるため、手動登録は不要です。既存のカタログがある場合は上書きしません。

VMDはアバターの動きを記録したファイルです。使うにはPMXモデルの導入が必要です。まだ2D表示の場合は [MMDの導入](reference_setup_ja.md#1-表情設定とpmxを導入する) へ進んでください。

## 動きを見る・切り替える

1. **設定 → 表示 → モーションを管理** を開きます。最初に選ばれている動きが自動でプレビューされます。
2. 一覧で動きを選ぶと、一度再生されます。「考える」などの名前で検索でき、分類・雰囲気・強さでも絞り込めます。もう一度見るには **プレビュー再生** を押します。
3. 会話で使う動きを変更する場合だけ **会話・待機で使用する** を切り替えます。変更はすぐ保存されます。プレビューを見るだけなら設定は変わりません。
4. 終わったら **プレビュー停止 → 閉じる** を押します。通常の待機へ戻れば完了です。

## 動かない・表示が崩れたとき

「利用不可」の項目はプレビューできません。一覧に表示される理由を確認してください。PMXの不一致やファイル不足などの対処は [エラー別の案内](vmd_catalog_reference_ja.md#エラーになった場合) にあります。

表示が大きく崩れたら **プレビュー停止 → 閉じる** で止めます。戻らなければアプリを終了して `run.bat` で再起動してください。素材を削除する必要はありません。起動できない場合は [復旧手順](backup_and_recovery_ja.md) を使います。
